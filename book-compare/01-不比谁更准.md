# 1 · 不比谁更准，比什么

## 1.1 那个问不出答案的问题

「四柱和占星哪个更准？」

这个问题听起来可以回答，实际不能 —— 不是因为难，是因为它缺了三样东西：

| 缺的 | 什么意思 |
| --- | --- |
| **共同的判准** | 「准」指什么？说中了一件事？说中了几成？用户觉得像？三种判准会给出三种排名 |
| **可检验的记录** | 没有人系统地记录过预言与结果的配对。零散的「说中了」是幸存者偏差 |
| **可比的输出** | 一个说「身弱喜印」，一个说「月亮在双鱼十二宫」。这两句话甚至不在同一个话题上 |

缺第三样最要命。两套系统若连输出的**类型**都不同，
「哪个更准」就像问「这把尺和这台秤哪个更准」。

## 1.2 换一个问法

把「准不准」换成「**它在算什么**」，问题立刻有了确定答案。

```
输入是什么？          → 看它的起例，照着做一遍就知道
输入里有多少真实天体？  → 算得出来
同一输入恒同一结果吗？  → 跑两遍
结果有多少种可能？     → 数得出来
最早的文献是什么？     → 查得到
```

这五个问题的答案是**事实**，不是立场。而且它们把九套系统分得很开 ——
分出来的组跟「东方／西方」、跟「科学／迷信」都不重合。

## 1.3 这本书不做的事

**不主张它们有效。** 说清楚一套系统在算什么，和相信它算得准，是两件事。
本书全程做前一件。

**不合成。** 不会出现「综合这九套看，今年宜……」这样的话。
理由在[另一本书](../book/09-问事.md)里讲过：这几套中土的系统都是同一组干支的
确定性函数，一致不构成互相印证。而跨到西方那一侧，连输入都不是同一个东西，
合成更无从谈起。

**不编细节。** 书目里不写 ISBN、不写页码、不写出版社 ——
这些若没有实物在手，写出来就是编的，而编出来的版本信息比没有更坏：
它看起来可核对。

## 1.4 这本书会出现的那种句子

```
✗  紫微斗数源自上古观星，是中国最早的天文占术之一。
✓  紫微斗数的「星」是按农历日时摆进十二宫的虚星；真正的紫微垣
   一次都不进计算。它的天文含量全在农历 —— 而农历要真算合朔与中气。
```

```
✗  塔罗的四元素与占星的四元素同源，可见东西方智慧殊途同归。
✓  塔罗起于 15 世纪意大利的纸牌游戏。「牌—行星—星座」的对应表是
   1888 年起金色黎明一系后加的注解，不进起牌。把注解当成本文，
   得到的「同源」是循环论证。
```

第二种句子更长，也更没有气势。但它可以核对。

## 1.5 两道分界，先说在这里

全书的结构就是两道分界，各占两到三章：

**第一道：天文含量。** 这套系统的输入里有多少真实天体的位置？
三档 —— 实测天体、历法派生、纯约定。界限很硬，不是程度之分。

**第二道：确定还是随机。** 同一输入是否恒得同一结果？

两道分界切出来的组**不一样**，而且都与「东方／西方」不重合。
这正是它们有用的地方：一条分法若只是把已知的分类重说一遍，就没有信息。
