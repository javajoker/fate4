# 5 · 四条算式

[第 3 章](03-同一组时刻.md)给了一条定义层面的重合，[第 4 章](04-岁差.md)给了一个
坐标系的分歧。这一章再往下挖四条 —— 每一条都能算出数来，
而且四条合起来说的是同一件事：

> **天文含量不是一个固定标签。它有来历，也会变。**

---

## 5.1 四余就是月亮的交点与远地点

「七政四余」的七政是日月五星，谁都知道那是天体。**四余常被当成虚构的符号，
其实不是** —— 其中三个是实打实的天文点：

| 四余 | 梵名 | 它是什么 | 西洋占星里的名字 |
| --- | --- | --- | --- |
| **罗睺** | Rāhu | 月亮轨道的**升交点** | North Node |
| **计都** | Ketu | 月亮轨道的**降交点** | South Node |
| **月孛** | — | 月亮轨道的**远地点** | Black Moon Lilith（平根版） |
| **紫炁** | — | ⚠️ 各家不一，周期约 28 年，无公认的天体对应 | —— |

**前三个不是类比，是同一批点。**

它们唐代随印度天文传入，而印度那一套与希腊化天文同源 ——
所以中土的四余与西洋占星的交点，是同一条传播链的两端。

### 怎么验

交点与远地点都有公认的周期，可以独立查到：

```
交点逆行一周     18.61 年     ← 著名的「沙罗」相关周期
近地点顺行一周    8.85 年
```

本项目算出来的正是这两个数（`NODE_PERIOD_YEARS`、`PERIGEE_PERIOD_YEARS`）。

还有一个更好认的区别：**交点逆行，近地点顺行**。
一年里交点退约 19.3°，近地点进约 40.7° —— 方向相反，由测试断言。

### 交点为什么会被编进号

因为它是**唯一有可观测后果的轨道要素**：日月食只发生在交点附近。
「罗睺吞日」这个说法不是比喻 —— 交点就是食发生的地方。

这一条很能说明四余的性质：它们进入占法，不是因为谁觉得该有四个余星，
是因为当时的天文学确实在算这几个点。

## 5.2 太岁：一条已经漂没了的连接

地支为什么是十二？

因为**木星约十二年绕天一周**。古人把黄道分成十二「次」，木星每年行一次，
以此纪年 —— 这叫**岁星纪年**，是地支纪年的来历。

**但木星的周期不是 12 年，是 11.862 年。**

于是每过十二年，木星实际多走一点：

```
12 / 11.862615 − 1 = 1.16%   →  每十二年多走 4.17°
累积到一整个「次」（30°）需要  →  约 86 年
```

古人早就发现了。这叫**超辰** —— 岁星跳过一次。汉代历法里就有超辰的改正。

### 然后他们做了一件决定性的事

既然真木星不听话，就造一个听话的：**太岁**，一个假想的天体，
与木星反向、严格十二年一周。

**地支纪年从此与木星脱钩。**

自《太初历》（公元前 104 年）至今，按十二年固定周期推算与木星实际位置
已经差了约 **740°，即二十四个多的「次」** —— 整整绕了两圈还多。

今天的「太岁」是一个纯粹的十二年计数器。它与天上那颗行星的关系，
**只剩下一个来历**。

### 这条最要紧

> 一套起源于观测的系统，可以在**保留全部术语**的同时，
> 把观测那一头悄悄换成约定 —— 而且换完之后外表毫无变化。

所以「天文含量」这个标签不能只看术语。**太岁、岁破、太岁当头**这些说法
今天仍在用，仍带着木星的名字，而木星已经不在了两千年。

## 5.3 紫微的命宫：一个纯算术函数

[第 2 章](02-天文含量.md)说紫微的「星」不是天上的星。这里把它算实。

命宫与身宫的起法（各家一致的那一层）：

```
自寅起正月，顺数至生月；再自该宫起子时，逆数至生时  →  命宫
同起点，顺数至生时                                →  身宫
```

**输入只有农历月与时辰两个整数。** 不查星历，不看节气，不要地点。

本项目把它实现出来（`ziweiPalaces`），并穷举了全部组合：

| | |
| --- | --- |
| 输入组合 | 12 月 × 12 时辰 = **144** |
| 不同的命宫 | **12**（十二宫都能落到） |
| 不同的（命宫, 身宫）对 | **72** —— 不是 144 |

最后一行是穷举得出的：**144 种输入只落到 72 对**，整整折半。
原因是命宫取 `月 − 时`、身宫取 `月 + 时`，于是
`(命 + 身) mod 12` 恒等于两倍的月宫 —— 一条可以验证的不变量，
也正是它把自由度砍掉一半。

这不是贬低。虚星体系自有其一致性，而且可复算。
但**它是算术，不是观测** —— 而这件事从起法本身就看得出来，不需要争论。

## 5.4 平气与定气：1645 年那条缝

这一条直接影响排盘，而且影响得比想象中大。

节气有两种排法：

| | 怎么定 |
| --- | --- |
| **平气** | 把一个回归年等分二十四份，每份 15.218 天。冬至实测，其余算术推 |
| **定气** | 太阳**真实**走到那个黄经的时刻 |

地球轨道是椭圆：近日点（一月初）附近太阳走得快，远日点（七月初）附近走得慢。
本项目算出来的单日行度是：

```
1 月 3 日   1.0188 °/日
7 月 5 日   0.9533 °/日        差约 6.9%
```

所以真实的节气间隔在 14.7 到 15.7 天之间摆动，而平气恒为 15.218 天。

### 差多少

两者在二至附近几乎重合（那是误差的驻点），在二分前后差得最多：

```
2026 年       夏至  −0.90 天
              清明  −2.38 天      ← 最大
              寒露  +1.49 天
```

**可以差到两天以上。**

### 为什么这是个实际问题

**中国历法 1645 年（《时宪历》行用）才从平气改定气。**

所以：1645 年之前出生的人，**当时的历书按平气排月，而今天任何一个排盘程序
按定气算** —— 两者给出的月柱可以不同。差两天，足够把一个人从一个月柱
挪到另一个。

本项目一律用**定气**。对 1645 年之后这是对的；对之前，它是
「按今天的算法回推」，而不是「当时的历书怎么写」。

**这是两个不同的问题，而大多数排盘工具不说自己在回答哪一个。**

## 5.5 四条合起来说的是什么

| 这一条 | 说明的 |
| --- | --- |
| 四余 | 有些看起来虚的，**本来是实的** |
| 太岁 | 有些曾经是实的，**现在只剩名字** |
| 紫微命宫 | 有些从来就是算术，**而起法本身就说得明白** |
| 平气定气 | 同一套术语底下，**算法换过，结果跟着换** |

所以回到[第 2 章](02-天文含量.md)那张三档表：它是一张**当下的**分类表，
不是一张起源表。一套系统今天落在哪一档，与它当初从哪儿来，是两件事。

而这四条都有一个共同的性质：**它们可以算，所以可以查。**
这正是这本书唯一想示范的方法 —— 凡是能算的，就不要靠说。

## 5.6 第五条：现在这两套可以当场起同一张盘

前面四条都是「算一个数，查一句话」。这一条不同 ——
它不是又一个对应，是把前面那些对应**合到一处**。

本项目现在能算日、月、水、金、火、木、土的黄经，
加上由时刻与地点定的上升点。于是同一组数，可以读两遍：

```
             七政四余          西洋古典
天体          七政 + 四余       七曜
分宫          十二宫，命宫起于上升   整宫制，第一宫起于上升
强弱          庙旺利陷          必然尊贵五项
昼夜          不构成规则分支     定义三分主星，不可省
```

**共用的那几行，在数据上是同一份**，不是分别算了两遍凑巧一样。
上升点是同一个上升点，木星的黄经是同一个黄经。

### 分野在读法，不在天

最后一行最值得看。昼夜盘在西洋古典里是一条**硬规则**：
同一颗星在同一度上，昼盘得三分之位，夜盘就不得 —— 换一颗星来得。
而七政四余里，昼夜不进规则。

同一片天，同一个时刻，一方把「太阳在地平上还是地平下」编进了规则，
另一方没有。

这就是这本书想说的那件事的最干净的一个例子：
**天给的是位置，规则是人定的。** 两套系统分歧的地方，
从来不是它们看到的天不同，而是它们决定拿天的哪一部分当回事。

### 顺带也就看清了「连续」是什么意思

[第 7 章](07-状态空间.md)说占星的状态空间不是有限集。
那一章只能声称，这一章可以演示：

把起盘时刻**挪动一秒**，上升点移动约 13 角秒 —— 换了一个值。
再挪一秒，再换一个。两张盘可以任意接近而不相同。

而同样挪动一秒的四柱盘，除非正落在节上或时辰界上，**逐字不变**。

这不是精度问题，是两种数学对象的分别：一个取值于连续统，
一个取值于有限集。那条界跨在东西之上 —— 七政四余与西洋占星在界的同一侧。
