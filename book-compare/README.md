# 测天，还是约定

### 九套占法的比较解剖

> 这本书不比较哪一套更准。它问的是另外几件事 —— 那几件有确定答案。

---

## 它要回答的问题

四柱、紫微斗数、六爻、梅花、大六壬、奇门遁甲、七政四余、西洋占星、塔罗。

九套东西，常被笼统地归为一类（「算命的」），或者笼统地分为两类（「东方／西方」）。
这本书想说明的是：**这两种分法都不对，而且有两条分法是对的，还算得出来。**

## 为什么「哪套更准」问不出答案

没有共同的判准，也没有可供检验的记录。把九套系统放进同一张准确率表里，
在方法上就不成立 —— 第 5 章会说明，其中有几套**根本不能放进同一张表**，
那是一个类别错误，不是数据不够。

## 可以问的五件事

| 问 | 为什么能答 |
| --- | --- |
| 输入是什么 | 看它的起例，照着做即可 |
| 输入里有多少真实天体位置 | **算得出来** |
| 同一输入是否恒得同一结果 | 跑两遍就知道 |
| 可能的结果有多少种 | **数得出来** |
| 最早的可考文献是什么 | 查得到 —— 而托名与可考要分开记 |

本书每一个数都来自可运行的代码
（[`packages/core/src/compare/`](../packages/core/src/compare/)），
每一条都有测试。书目在 [`reference/`](../reference/)。

## 先把结论放在前面

**一、「东方 vs 西方」不是一条有解释力的界。**
西洋占星与中土的七政四余是同一类东西（都测天）；
塔罗与其余八套都不同类（天文含量为零）。这条界切不开任何有意义的东西。

**二、有几套系统在某一层用的是同一把尺。**
二十四节气的十二**中气**与西方黄道十二宫的**入宫点**，
定义黄经都是 30° 的整数倍 —— **它们是同一组时刻**。
六壬的月将就是太阳所在的宫。四柱的月建落在它们正中间，偏移 15°。

**三、更要紧的那条界是确定与随机。**
确定性系统问「这个时刻的结构是什么」，可复算、可对质；
随机系统问「这一次抽到了什么」，复算没有意义。
把两者放进同一张准确率表，是类别错误。

**四、这本书不主张它们有效。**
它只说明它们**各自在算什么**，以及这些算法之间哪些连接是真的、哪些是后加的。
与[另一本书](../book/11-它算不出什么.md)同一条底线：
说清楚它算什么，和相信它算得准，是两件事。
