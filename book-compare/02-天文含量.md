# 2 · 第一道分界：天文含量

> 这套系统的输入里，有多少是真实天体的位置？

这个问题有确定答案，因为起例是写明的 —— 照着做一遍，就知道要不要查星历。

---

## 2.1 三档，界限很硬

| 档 | 意思 | 判据 |
| --- | --- | --- |
| **实测天体** | 输入直接是某个天体的黄经 | 不算星历就起不了盘 |
| **历法派生** | 输入是历法上的日期，而该历法由实测天象定 | 要一本准确的历书，但不必自己算天 |
| **纯约定** | 输入与天象无关 | 一张桌子就够了 |

这不是程度之分。第一档与第二档之间隔着一整套星历计算；
第二档与第三档之间隔着「要不要知道今天是哪天」。

## 2.2 九套系统的落位

```
实测天体    七政四余    西洋占星

历法派生    四柱    紫微斗数    六爻    梅花    大六壬    奇门遁甲

纯约定      塔罗
```

**第一件该注意的事**：这条界把西洋占星和七政四余放在了一起，
把它们和四柱分开了。「东方／西方」在这里完全失效。

**第二件**：塔罗落单。它是九套里唯一一个起盘不需要知道今天是哪天的。

## 2.3 逐套说明

### 实测天体

**七政四余**与**西洋占星**的输入是日、月、五星的实际黄经，
以及（占星）由时刻与地点定的上升点。**不算星历就起不了盘。**

七政四余唐代随佛经与西域历法传入，与西洋占星同源。
清代以降它在中土式微，而子平与紫微盛行 —— 一个可能的原因是
后两者**不需要星历**，门槛低得多。

### 历法派生

这六套都要知道「今天是哪天」，但不必自己算天。
它们的天文含量**全部经由历法间接获得**，而中土的历法本身是实测的：

| 系统 | 天文含量在哪 |
| --- | --- |
| **四柱** | 月柱由二十四节气的「节」划分，节是太阳黄经的 15° 整数倍。时柱由真太阳时定，牵涉经度与均时差。**但年、日两柱是六十甲子的连续计数，与天象无关** |
| **大六壬** | 月将每中气一换，而中气是太阳黄经的 30° 整数倍 —— 详见[第 3 章](03-同一组时刻.md)，这一套的天文含量比看上去高 |
| **奇门** | 定局看节气三元 |
| **紫微** | 全在农历：定朔要真算合朔，置闰要看中气 |
| **六爻 / 梅花** | 断卦用月建日辰；按时起卦取农历数。掷钱那一步与天象无关 |

### ⚠️ 紫微斗数：最容易被误解的一套

它的「星」—— 紫微、天府、贪狼、廉贞 —— **不是天上的星**。
它们是按**农历日与时辰的算术规则**摆进十二宫的**虚星**。
真正的紫微垣（北极一带的星官）一次都不进计算。

起盘不需要星历，只需要农历日期。

这个区分不是贬低。虚星体系自有其一致性，而且可复算。
问题只在于把它说成「观星」是不对的 —— 那是把它归错了档。

### 纯约定

**塔罗**的起牌只需要洗牌与切牌。不需要时刻，不需要地点，不需要星历。

流行的「权杖对应火」「皇帝对应白羊」这类对应表，是 **1888 年起
金色黎明一系的注解**，不是它的来历，也不进起牌。
把注解当成本文，得到的「塔罗与占星同源」是循环论证。

## 2.4 这一档分法说明了什么

它说明的是一件很朴素的事：**这几套系统接的是不同的输入。**

接实测天体的那两套，与天文学共用同一套计算；它们的星历部分**对错可验证**
（这件事托勒密本人最清楚 —— 《天文学大成》与《四书》出自同一支笔）。

接历法的那六套，验证只能到历法为止：节气算得对不对可以查，
而「寅月生人木旺」对不对，查不了。

接纯约定的那一套，连历法这一层都没有。

**但要当心**：天文含量高**不等于**更可信。
一套系统可以用极精确的行星位置，再接上一套毫无依据的解释规则 ——
精确的输入不会让输出变得可靠。这一条下一章还会遇到。
