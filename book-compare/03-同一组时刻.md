# 3 · 同一组时刻

> 全书最硬的一条连接，而且它不需要任何诠释 —— 是定义的直接后果。

---

## 3.1 两套格子

**二十四节气**把太阳黄经分成 24 段，每段 15°。它们分两类：

```
节   立春 315°   惊蛰 345°   清明  15°   立夏  45°  …
气   雨水 330°   春分   0°   谷雨  30°   小满  60°  …
```

把这些数排一排，规律一眼可见：

- **十二个「气」（中气）的黄经，恰为 30° 的整数倍**
- **十二个「节」的黄经，恰为 30k + 15**

**西方回归黄道十二宫**的入宫点呢？

```
白羊 0°   金牛 30°   双子 60°   巨蟹 90°  …
```

**也是 30° 的整数倍。**

## 3.2 它们是同一组时刻

不是「相似」，不是「对应」，不是「暗合」—— **是同一组时刻**。

太阳到达黄经 330° 的那一瞬间，在中土的历法里叫**雨水**，
在西方的星历里叫**太阳入双鱼**。同一瞬间，两个名字。

本项目把二十四节气与十二宫摆在同一条黄经轴上逐格对照：

| 黄经 | 中气 | 节 | 入宫 |
| --- | --- | --- | --- |
| 0 | 春分 | — | 白羊 |
| 15 | — | 清明 | — |
| 30 | 谷雨 | — | 金牛 |
| 45 | — | 立夏 | — |
| 60 | 小满 | — | 双子 |
| 75 | — | 芒种 | — |
| 90 | 夏至 | — | 巨蟹 |
| … | | | |
| 330 | 雨水 | — | 双鱼 |
| 345 | — | 惊蛰 | — |

**24 行里，有中气的必有入宫点，有节的必无。无一例外。**
这条由测试逐行断言（`zodiacVsZhongqi`）。

## 3.3 节落在正中间

十二个「节」落在这些刻度的**正中间**，偏移恰好 15°。

而四柱的**月建**是由节划分的 —— 寅月从立春（315°）起，到惊蛰（345°）止。

于是：

```
中气 / 入宫点     0°   30°   60°   90°  …     ← 六壬的月将换在这里
节 / 月建界      15°   45°   75°  105°  …     ← 四柱的月柱换在这里
```

**两套格子同样大，错开半格。**

四柱与西洋占星在「月」这一层用的是同一把尺，只是零点差了 15°。
一个寅月的人，太阳跨了水瓶的后半与双鱼的前半。

这件事与任何象征体系无关，也不需要「东西方智慧相通」这种说法来解释。
两边都在把太阳走过的那一圈分成十二份，分法只差半格。

## 3.4 六壬的月将，就是太阳星座

这一条更直接。

六壬的**月将**每**中气**一换，而中气即入宫点。所以月将就是
**太阳当前所在的黄道宫**，换了一套地支的名字：

| 月将 | 起于中气 | 太阳所在 |
| --- | --- | --- |
| 亥（登明） | 雨水 330° | 双鱼 |
| 戌（河魁） | 春分 0° | 白羊 |
| 酉（从魁） | 谷雨 30° | 金牛 |
| 申（传送） | 小满 60° | 双子 |
| 未（小吉） | 夏至 90° | 巨蟹 |
| 午（胜光） | 大暑 120° | 狮子 |
| 巳（太乙） | 处暑 150° | 处女 |
| 辰（天罡） | 秋分 180° | 天秤 |
| 卯（太冲） | 霜降 210° | 天蝎 |
| 寅（功曹） | 小雪 240° | 射手 |
| 丑（大吉） | 冬至 270° | 摩羯 |
| 子（神后） | 大寒 300° | 水瓶 |

十二条逐一对上，由测试断言。

### 地支为什么逆行

注意左边那一列：亥、戌、酉、申…… 太阳向前走，地支往后退。

这不是巧合，也有来历：月将是**太阳在天盘上的位置**，
而六壬的天盘随天左旋、地盘不动。从地上看去，太阳每月退一宫。

**「月将加时」就是把太阳位置叠到当前时辰上转出天盘** ——
一个朴素但真实的天球模型。六壬这一套的天文含量，比它的名声高得多。

## 3.5 别把这条推太远

以上全部是**定义层面的重合**。它说明的是：

> 这几套系统在分割太阳周年视运动这件事上，用的是同一把尺。

它**不**说明：

- 它们同源（没有证据表明中土的节气与希腊的黄道十二宫有传播关系；
  两边各自把一个圆分成十二份，是独立的、也是自然的选择）
- 它们的解释体系相通（「寅月生人木旺」与「双鱼座温柔」之间没有任何桥）
- 其中任何一套因此更可信

**同一把尺，不等于同一套读数规则。** 这是全书反复要守的那条线：
输入的那一层可以验证、可以对照；输出的那一层不能。
