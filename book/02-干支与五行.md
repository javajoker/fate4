# 2 · 干支与五行

这一章把后面要用的符号一次讲完。它们不多：十个天干、十二个地支、
五行、十神。读完这一章，你就能看懂屏幕上的那张盘。

---

## 2.1 天干与地支：一套六十进制的记时法

**十天干**：甲 乙 丙 丁 戊 己 庚 辛 壬 癸
**十二地支**：子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥

天干配地支，**单配单、双配双**，于是不是 120 组而是 **60** 组：
甲子、乙丑、丙寅……癸亥，然后回到甲子。这就是「六十甲子」，
一个周期六十。

这套东西最初就是**记时的符号**，跟公元纪年、星期几是同类的东西 ——
年月日时各记一组，就是四柱。它之所以能被拿来「算」，
是因为后人给每个符号附加了五行属性，于是符号之间有了可计算的关系。

> 本项目把这一层做成纯代数：天干地支的序号、六十甲子的索引、
> 旬空的计算，全是取模运算。不查表，故不会抄错。

---

## 2.2 五行：五个类，以及它们之间的两种关系

**木 火 土 金 水。**

它们不是五种物质，是**五个类**。理解成「五个相位」或「五种状态」
比理解成材料更接近原意。

两种关系：

```
相生    木生火  火生土  土生金  金生水  水生木      （一个环）
相克    木克土  土克水  水克火  火克金  金克木      （另一个环，隔一位）
```

把五行摆成一个五角星：外圈相邻是生，内部连线是克。

这两个环是整套系统的**计算核心**。[第 4 章](04-力量.md)讲的「传导」
就是让这两个环在十个载体上反复作用到收敛。

### 阴阳：每一行再分两半

天干里，甲丙戊庚壬为阳，乙丁己辛癸为阴。于是五行乘以阴阳，
得到**十类载体**：

| | 阳 | 阴 |
| 木 | 甲 | 乙 |
| 火 | 丙 | 丁 |
| 土 | 戊 | 己 |
| 金 | 庚 | 辛 |
| 水 | 壬 | 癸 |

本项目内部算的就是这十类的权重。你在「力量结构」那一页看到的十条，
就是它们。

> 阴阳之分在传导里是有系数的：同性相生比异性相生弱一些（「同性相生力减」），
> 这是传统说法，本项目把它做成参数 `propagation.polarity`，可改。

## 2.3 地支藏干：为什么地支比天干复杂

天干一个字就是一个五行。地支不是 —— **每个地支里「藏」着一到三个天干**。

```
子 ── 癸
丑 ── 己 癸 辛
寅 ── 甲 丙 戊
卯 ── 乙
辰 ── 戊 乙 癸
...
```

藏得最多的是「辰戌丑未」四个，各藏三个 —— 它们被称为**四墓库**，
后面[第 5 章](05-结构.md)讲「库开库闭」时还会见到。

藏干分三档：

| 档 | 叫法 | 大意 |
| 第一个 | **本气** | 这个地支的主属性 |
| 第二个 | **中气** | 次要的那一个 |
| 第三个 | **余气** | 残留的那一点 |

**各占多少权重，典籍里没有数字。** 这是整套系统里最明显的一处空白，
各家各派给的比例差别很大。本项目的默认值写在
[`params/default.yaml`](../params/default.yaml) 里并标注了 `[校准]`，
意思是「这是一个待校准的数，不是一条定理」。

## 2.4 日主：代表「你」的那个字

四柱八个字里，**日柱的天干**代表命主本人，称为**日主**（或日元）。

```
      年      月      日      时
      庚      辛      丁 ←─ 日主    丁
      午      巳      丑            未
```

这是一条约定，不是推出来的。从这条约定出发，整盘的其余七个字
才有了「对你而言是什么」的身份 —— 那就是十神。

---

## 2.5 十神：七个字相对于你的身份

把盘里每一个字的五行，与日主的五行作比较，按**生克方向**与**阴阳同异**
分成十类：

| 关系 | 同性 | 异性 |
| 与我同类 | **比肩** | **劫财** |
| 我生者 | **食神** | **伤官** |
| 我克者 | **偏财** | **正财** |
| 克我者 | **七杀** | **正官** |
| 生我者 | **偏印** | **正印** |

这十个名字是术语，但背后的意思很朴素：

| 十神 | 它在说哪一类事 |
| 比肩 | 同辈、平起平坐、一起扛 |
| 劫财 | 同辈，但争同一件东西 |
| 食神 | 表达、创作、享受，温和那一路 |
| 伤官 | 表达，但锋芒外露、不服框框 |
| 偏财 | 流动的钱、机会财、人情往来 |
| 正财 | 固定的钱、务实的所得、日常开销 |
| 七杀 | 压力、竞争、硬碰硬 |
| 正官 | 规矩、职位、被认可的秩序 |
| 偏印 | 独处、冷门的钻研、精神支持 |
| 正印 | 照顾、学习、靠山 |

> 这张表在本项目里是**叙述素材**，不参与计算。计算用的是五行权重；
> 十神只是把五行权重换个名字说出来，好让描述落到具体的生活面上。
> 移动版那个「说人话」的版本，用的就是右边这一列。

### 同党与异党

十神还可以粗分成两边：

```
同党（帮日主的）   比肩 劫财 偏印 正印
异党（耗日主的）   食神 伤官 偏财 正财 七杀 正官
```

两边的权重之比，就是判断**旺衰**的主要依据。见[第 6 章](06-断论.md)。

## 2.6 宫位：哪一柱管哪一类关系

四柱的八个位置各自对应一类关系。本项目用的是**八宫**，天干地支分开：

| 位置 | 宫 | 传统对应 |
| 年干 | 祖上宫 | 家世、来处 |
| 年支 | 根基宫 | 出身根底、早年 |
| 月干 | 父母兄弟宫 | 父母、同辈 |
| 月支 | 门户宫 | 所处的环境、工作面 |
| 日干 | 自身 | 日主，就是你 |
| 日支 | 配偶宫 | 配偶、身边最近的人 |
| 时干 | 志向宫 | 志趣、所向 |
| 时支 | 子女宫 | 子女、晚年、往后的去向 |

另有两个不在四柱之内的位置也参与神煞的落宫：**命宫**与**胎元**。

于是「看配偶」有两条线索：**星**（代表配偶的那个十神在盘里怎么样）
与**宫**（日支这个位置怎么样）。两条线索可能一致，也可能相反 ——
本项目把两者**分开报**，并照实说明它们一致还是相反，
而不是合成一个「婚姻分」。见[第 6 章](06-断论.md)。

---

## 2.7 这一章最该记住的

1. **干支最初只是记时符号。** 五行属性是后人附加的一层。
2. **五行是五个类，有生、克两个环。** 整套计算就是这两个环在十类载体上迭代。
3. **地支藏干的比例没有典籍数字。** 它是参数，不是定理 —— 这一点很重要。
4. **十神是五行关系换个说法。** 它不参与计算，只参与叙述。
5. **星与宫是两条线索，不合成一个分数。**

下一章讲排盘 —— 这一套符号怎么从一个公历时刻算出来，
以及为什么这一步是全书唯一「可以验证对错」的一步。
