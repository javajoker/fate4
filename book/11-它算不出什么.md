# 11 · 它算不出什么

这是全书最要紧的一章。前面十章讲这套系统在算什么，
这一章讲它**不**算什么 —— 以及为什么这条线是用代码守住的，
而不是靠自觉。

---

## 11.1 它不预测事件

**它不会告诉你哪年结婚、哪年破财、哪年升迁、哪年生病。**

它能给的是：按一套传统规则，你的出生时刻折算出的结构是什么样子，
以及这个结构在哪些时段与外部干支的张力较大。

```
它会说    这几年「与钱、务实的往来」这一路张力偏大
它不会说  你 2027 年会破财
```

**张力大不等于会出事，张力小也不等于太平。**
这个区别是整本书的底线。

为什么不预测：因为这套模型的输入只有一个出生时刻。
一个时刻里没有你的职业、健康状况、所在国家、经济周期、
你今天做的决定。拿它去推一件具体的事，需要的信息它根本没有。

---

## 11.2 守住这条线的是代码，不是自觉

本项目有一道**措辞守卫**，在输出送达读者之前逐句扫描。违规就拦下，
不打印。

### 它拦的是形状，不是词

朴素的敏感词黑名单在这个领域两头都会失败：

| 失败方向 | 例子 |
| --- | --- |
| **误杀** | 禁掉「病」—— 可「病药」是本系统的取用神法之一，「疾病」是神煞的传统语义标签。禁掉它等于禁掉自己的术语表 |
| **漏放** | 「你 2027 年会离婚」—— 这句话里**没有任何一个词单独有问题** |

所以守卫拦的是**断言的形状**：「主体 + 情态 + 后果」。
词汇本身一律放行。

### 两种模式

| 模式 | 意思 |
| --- | --- |
| **禁止** | 命中即违规 |
| **需框定** | 命中后，同句（或同段）里必须带上框定语，否则违规 |

第二种是给传统语汇用的。「血光」出现在神煞名表里没问题 ——
一个孤零零的名词不构成对谁的断言；但它出现在**正文**里，
就必须写成「传统上此煞与灾厄一类语汇相联系」，
而不是「此煞主灾厄」。

### 几条实际的规则

```
绝对情态     必然、必定、必将、一定会、注定、势必
行动指令     建议你去…、最好去…、千万不要…
六爻成败词   可成、不成、难成、必得、立至、有望
相貌判断     整类禁止
第三方描述   「你配偶是什么样的人」整类禁止
脏腑段       必须同时带传统框定语与免责导向，缺一即拦
趋避段       同上
```

### 人话层更严，不是更松

去掉术语之后，天然的对冲也没了：

> 「用神取木」晦涩，读者知道自己在看一个模型；
> 「你适合往东发展」具体可执行，读起来像忠告。

所以人话层在放开第二人称（它要用「你」才平易近人）的同时，
**另加了六条更硬的禁令**：不许出方位、属相、颜色、幸运数字；
不许说「适合做什么职业」；不许用祈使句；不许评相貌；
不许描述第三方；出现术语时同段必须说明它来自一套传统模型。

### 反向对照

只说「扫描全绿」是不够的 —— 全绿也可能是因为扫描根本没跑到东西。
所以另有一条断言：**植入一句违规必须被逮到**。

```
"你 2030 年必然离婚。"        → 必须被拦
"你的病难愈。"                → 必须被拦
"建议你去投资买房。"          → 必须被拦
"日主偏弱。"                  → 必须放行
```

最后一条同样要紧：若连正常的话也拦，守卫就成了一个只会说「不」的东西。

## 11.3 明确不做的事

| 不做 | 为什么 |
| --- | --- |
| **吉凶总分** | 没有任何典籍给过合成权重。编一个出来，读者看到的是有精度外观、实则是编的数 |
| **红绿配色** | 顺逆指数低不等于「凶」。图表一旦染红绿，有序量立刻被读成好坏。这条写在参数里且**不可关闭** |
| **合盘分数** | 见下节 —— 这是整个项目里最该克制的一处 |
| **描述第三方** | 把一份推演套到没同意过的人身上 |
| **医疗、法律、财务建议** | 不在能力范围内，也不在许可范围内 |
| **健康类给预后与时间窗** | 六爻的健康类占事受限：不给病名、不给好转与否、不给时间 |
| **把问题文本哈希进起卦** | 那是发明一种传统里没有的方法，还伪装成传统 |
| **推送「今日运势」** | 每天给一条关于明天的话，正是这套东西最该避开的形态 |
| **用标注调参数** | 事后偏误会直接进模型，系统会朝「让用户觉得准」漂移 |


### 11.3.1 合盘为什么一个分数都不给

合盘是这个项目里**最该克制的一处**，而克制的办法只有一个：不加总。

本项目别处是给数的 —— 流年那边有顺逆指数。那为什么这里不给？

| | 流年的那个数 | 合盘的那个数 |
| --- | --- | --- |
| 说的是 | 一个人与一段时间 | **两个具体的人** |
| 读者会怎么读 | 今年这一段合不合我的结构 | **我们合不合适** |
| 读错了的代价 | 明年还能再看一次 | 可能促成一个**不可撤回**的决定 |
| 牵连谁 | 只有自己 | **一个没有参与的人** |

无论措辞怎么框，「我们合盘 42 分」只会被读成一句关于这段关系的判决 ——
因为读者正是为那句判决来的。

所以合盘页只列**逐条的结构关系**：哪两个干相合、哪两个支相冲、
一方的用神在另一方盘里占多少权重。读者自己看。
**不替他加总，因为加总就是替他下结论。**

> 做一个漂亮的「契合度 78%」只要半小时。
> 而那半小时会把这个项目其余部分的全部克制一笔勾销。

代码里 `score` 这个字段的类型就是 `null` —— 不是 `number | null`，
是 `null`。有一条测试在源码里扫，确保没人日后加一个打分函数
再在出口处置空。

### 11.3.2 还有两件合盘不做的事

**不出对任何一方的人格描述。** 报告层对「他人」已有先例：人格、身心、
六亲几节结构性略去。合盘沿用同一条线 —— 它只产出两张盘之间的**关系**。
想看某一方的描述，就去单独排那一张盘，并且自己清楚那是谁的盘。

**紫微合盘不收。** 不是忘了：各家取法差异极大，而本项目没有可靠底本。
合盘本来就是最容易被当成判决的地方，再加上一套来历不明的规则，
等于拿编的东西去影响一个人对另一个人的看法。

## 11.4 还有哪些是「不确定」而非「不做」

诚实地讲，有几处是已知的弱点，不是刻意的克制：

| | 状况 |
| --- | --- |
| **藏干比例** | 典籍没给过数字。本项目填了一组，标了「待校准」 |
| **调候 120 格** | **凭记忆转录，尚未经实体书核对。** 31 格各家有异，8 格已列出不同版本 |
| **奇门的局数表** | 72 个数字同样是凭记忆转录的 |
| **六壬的几处取法** | 别责、八专、伏吟的取法与涉害的深浅计算，各家不一 |
| **L1–L3 的数值** | 没有外部真值可对，只能验证内部不变量与顺序无关性 |
| **L4 的判定** | 只能与人工判读比一致率，而人工判读本身也不唯一 |

这些全部写在 [`docs/11-validation.md`](../docs/11-validation.md) 的待核对清单里，
按项编号，注明来源与风险。**没有藏起来。**

## 11.5 那它到底能用来干什么

说了这么多不能，说说能的。

**第一，它是一个自洽的、可复算的、可审计的实现。**
同一份输入永远得到同一份输出；每一条结论都能展开到数；
每一个参数都能改，改完能立刻看到差多少。
就「把一套口传的东西写成明确规则」而言，它做到了。

**第二，它让你看得见这套东西的不确定性在哪。**
去参数校准面板拖一下藏干比例，看着「身弱」变成「中和」——
那一刻你学到的东西，比读十篇「八字是否科学」的文章都多。

**第三，「回看」页让你自己检验它。**
不是听它说准不准，是自己标，自己看账。而且那本账
**按模型自己的置信度分栏** —— 最有意思的问题从来不是「它准不准」，
是「它说有把握的时候，是不是真的更准」。

**第四，作为一种自我省思的素材。**
「这一路在你的结构里分量足但位置不稳」—— 这句话的价值不在于它是真的，
而在于它给了你一个你平时不会用的角度去看一件事。
这个用法是正当的，也是这套东西在今天最合适的位置。

---

## 11.6 这一章最该记住的

1. **它不预测事件。** 张力大 ≠ 会出事。
2. **守住这条线的是代码** —— 逐句扫描，拦形状不拦词，另有反向对照。
3. **人话层比术语层更严**，因为去掉术语等于去掉对冲。
4. **已知的弱点全部写在待核对清单里**，没有藏。
5. **最正当的用法是：当素材，不当预言；自己标，自己看账。**

最后一章讲怎么改它。
