# 1 · 它在算什么

你输入一个出生时刻，它输出一页描述。这一章讲中间发生了什么 —— 不讲细节，
只把整条流水线铺开，让你知道后面每一章在修哪一段。

---

## 1.1 输入只有一个东西

**出生的那一刻，加上出生地点。**

就这些。没有姓名，没有照片，没有你填的问卷。
这件事本身就说明了这套系统的性质：它不认识你，
它只认识一个时刻。所有的描述都是从那个时刻的**记时符号**推出来的。

> 地点是必要的，因为这套系统用的是**真太阳时**（见[第 3 章](03-排盘.md)）。
> 同一个钟点，上海和乌鲁木齐的太阳位置差了快两小时 ——
> 够改变「时辰」，进而改变四柱里的一柱。

---

## 1.2 第一步：把时刻写成符号

公历的「1990 年 5 月 12 日 14 时 30 分」在这套系统里要改写成四组符号：

```
      年      月      日      时
      庚      辛      丁      丁
      午      巳      丑      未
```

这四组（每组一个**天干**一个**地支**）就是**四柱**，也叫**八字** —— 八个字。

改写不是查日历那么简单，有三处必须算对：

| 要算的 | 为什么难 |
| **月柱的分界** | 不按公历月，按**节气**。五月初到芒种之前都算巳月 |
| **时柱的分界** | 不按钟表时，按**真太阳时**（经度 + 均时差） |
| **日柱的分界** | 子时跨午夜，归哪一天各家不一 —— 进参数 |

这一步**对错是客观可验证的**，与信不信无关。本项目用天文算法算节气，
对香港天文台公布的 240 个节气时刻，最大偏差 **42 秒**。
详见[第 3 章](03-排盘.md)。

---

## 1.3 第二步：把符号变成力量

八个字只是八个标签。要想「算」，得先把它们变成可以加减的量。

这套系统的做法是：每个字都代表若干**五行载体**（木、火、土、金、水，
再分阴阳，共十类），各自带一个权重。

```
丁（天干，火）                   → 阴火 40
卯（地支，本气乙木）             → 阴木 48
                 （中气…余气…）   → 其余按比例下发
```

于是「八个字」变成了**十个数**。后面所有的计算都在这十个数上做。

> 这一步是整套系统里最「工程」的一段，也是各家差异最大的一段：
> 地支里藏着的那几个干各占多少分量，没有任何典籍给过数字。
> 本项目把它们全部做成**可改的参数**，并写明默认值的出处。
> 见[第 4 章](04-力量.md)与[第 12 章](12-自己调参.md)。

---

## 1.4 第三步：让它们互相作用

十个数不是各自静止的。五行之间有**生**与**克**：

```
生：木 → 火 → 土 → 金 → 水 → 木
克：木 → 土 → 水 → 火 → 金 → 木
```

本项目把这件事做成**迭代到收敛**：每一轮里，每个载体按生克关系
对别的载体施加影响，所有载体**同步**更新，再跑下一轮，直到数值不再变动。

同步更新是要紧的：若改成一个个依次更新，结果会依赖于「先算谁」，
而「先算谁」在典籍里没有规定。本项目有一条测试把载体顺序**随机打乱 200 次**，
断言结果一致 —— 顺序无关性是构造保证，不是巧合。

详见[第 4 章](04-力量.md)。

---

## 1.5 第四步：才开始「断」

到这一步，手里有的是一组收敛后的数。把它们归类、比较，才得到那些
你在屏幕上看到的词：

| 结论 | 大意 |
| **旺衰** | 日主（代表你的那个字）在整盘里是强是弱，五档 |
| **用神** | 这个结构最需要补的是哪一行 |
| **格局** | 这个结构落在传统的哪一类里 |
| **宫位六亲** | 父母、配偶、兄弟、子女各自的结构位置 |

**每一条结论都带着它的推导链。** 屏幕上那句「日主偏弱」旁边一定有一个
可以展开的东西，里面是：哪些载体、各多少权重、过了哪条阈值、
差阈值多远。没有推导链的结论不允许进报告 —— 这是本项目的硬规矩。

还有一条同样硬的规矩：**置信度低的结论必须同时给出另一种读法**。
如果一张盘的同党占比离档界只差 0.3%，报告会说「这张盘在界上，
两种读法都成立」，并把两种都列出来 —— 而不是挑一个说得斩钉截铁。

详见[第 6 章](06-断论.md)。

---

## 1.6 第五步：加上时间

上面算的是**本命** —— 不随时间变的那一层。再往上才是时间层：

```
大运   每十年一换，由出生月柱顺推或逆推
流年   每年一换
流月   每月
流日   每天
```

大运与流年会**重新跑一遍前面的计算**：把那一步的干支当作额外的载体
铺进盘里，重算权重、重算传导、重出结论。所以「今年旺衰如何」
与「本命旺衰如何」是两个不同的数。

流月与流日**不重算权重**。它们只做事件匹配 —— 看这个月的地支
有没有冲到盘里某个关键位置。这个分界是刻意的：
**月、日是引动的扳机，不是力量的来源**。把流日也算进权重，
等于说一个人的力量每天都在大幅变动，那不是这套理论的说法。

详见[第 7 章](07-时间.md)。

## 1.7 全景

```
出生时刻 + 地点
      │
      ├─ L0 排盘    节气 / 真太阳时 / 四柱 / 起运          ← 可客观验证
      │
      ├─ L1 配重    八个字 → 十类五行载体的权重
      │
      ├─ L2 结构    会合冲刑害破：察（恒出）+ 改（可关）
      │
      ├─ L3 传导    生克迭代到收敛，顺序无关
      │
      ├─ L4 断论    旺衰 / 用神 / 格局 / 六亲，每条带推导链
      │
      ├─ 神煞       叙述素材，不进权重
      │
      ├─ L5 时间    大运 / 流年重跑 L1–L4；流月 / 流日只匹配事件
      │
      └─ L6 报告    组装 + 措辞守卫 + 简繁转换
```

另外还有三台**不要生辰**的引擎 —— 六爻、六壬、奇门。
它们算的不是「这个人是什么结构」，而是「此刻问这件事，象是什么结构」。
见[第 9 章](09-问事.md)。

---

## 1.8 这一章最该记住的

1. **输入只有时刻与地点。** 系统不认识你，只认识一个时刻。
2. **排盘可验证，断论不可验证。** 前者是天文与历法，后者是一套传统规则。
   这两段的性质完全不同，别混在一起评价。
3. **每条结论都带推导链。** 看不到推导的结论，在这个项目里是 bug。
4. **月日是扳机，不是力量。** 这条分界决定了很多东西。
