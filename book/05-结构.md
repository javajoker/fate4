# 5 · 结构

地支之间、天干之间有一组固定的两两（或三三）关系：会、合、冲、刑、害、破。
它们是传统断法里最热闹的一部分，也是本项目最近才想清楚一件事的地方。

---

## 5.1 六种关系

| 名 | 组成 | 传统大意 |
| **三会** | 三个同方位的支（寅卯辰会东方木） | 范围最大，整个方位成一片 |
| **三合** | 三个隔四位的支（申子辰合水） | 成局，三者合力转向一行 |
| **半合** | 三合缺一 | 力量减半 |
| **六合** | 两支相合（子丑合土） | 两者之间的私下结合 |
| **冲** | 两支相对（子午冲） | 对立、动摇 |
| **刑** | 三支互刑或自刑 | 纠缠、磨损 |
| **害** | 两支相害 | 暗中损耗 |
| **破** | 两支相破 | 轻微的破损 |

天干也有**五合**（甲己合土）与**相冲**。

### 结算有次序

同一张盘上这些关系可能同时成立，而且会互相干扰。本项目按一条优先级结算：

```
三会 > 三合 > 半合 > 六合 > 天干五合 > 冲 > 天干冲 > 刑 > 害 > 破
```

理由：**范围大者优先，成局者优先，静者先于动者。**
三会是三支同方，格局最大；六合是两支之私；冲刑害破是既成结构上的扰动。

还有两种要单独裁决的情形：

| | |
| **争合 / 妒合** | 一个支同时进了两个合 —— 谁也合不成，互相牵制 |
| **合而逢冲** | 合到一半被冲开 —— 比较双方的力量，强者胜 |

裁决的依据必须留在推导链里。「为什么这个合没化成」是读者一定会问的问题，
答不出来就等于没算。

## 5.2 墓库：开与闭

辰、戌、丑、未这四个支各藏三个天干，传统称它们为**墓库** ——
里面的东西是「存着的」，平时不发挥作用。

```
被冲，或被刑  →  库开，里面的中气余气释放出来
没被冲没被刑  →  库闭，里面的东西打折
```

注意一个细节：**本气是墙本身，不受开闭影响**，只有中气与余气是「库里的东西」。
这一条很容易写错。

## 5.3 「察」与「改」是两件事

这是本项目在这一层最要紧的一个区分，也是最近才分清楚的。

这一层实际在做两件可以分开的事：

| | 是什么 | 谁在用 |
| **察** | 认出发生了哪些会合冲刑害破、哪些库开了 | 神煞的状态、应期规则、生命曲线节点的理由、报告的结构一节 |
| **改** | 据此缩放载体的权重与活性 | 下一层（传导）的输入 |

「察」是**观察**，「改」是**干预**。

### 两种说法

- 一说：合化会改变「场上有什么」。甲木化土之后它就不是木了，
  后面按木算生克是错的 —— 所以必须在传导之前先改。
- 另一说：合化刑冲本来**就是**五行力量消长的结果，
  由传导一并算出即可，不该在传导之前先改一道。

两说都有道理。本项目的处理是：**做成一个开关，而且只关「改」，不关「察」。**

```
structure.rewriteCarriers: false    ← 当前默认：只察不改
```

### 为什么必须分开

因为曾经没分开，代价不小。有一次为了试第二种说法，
把整段计算直接关掉、事件列表直接写成空的。结果是：

- 报告的「结构」一节整节空白
- 神煞的状态修饰失效（它要读事件）
- 应期里依赖事件的六条规则在本命这一侧永不触发
- 生命曲线的节点少了一类理由
- 而流年流月那一侧走的是另一条代码路径，**全都正常**

于是同一份报告里，**本命说没有，流年说有**。而所有这些都没有报错。

现在两件事是分开的：关掉「改」时，仍照常跑完整的计算去取事件，
只是把改过的那份丢掉、保留原来的权重。事件因此**逐条相同**，
由测试断言。

## 5.4 关掉「改」之后差多少

这类问题不该靠直觉回答。实测 **120 张盘**（1950–2009 每三年取三个时刻 × 两性），
两档逐张对照：

| | 结果 |
| 有结构事件的盘 | **120 / 120** —— 事件开关前后逐条相同 |
| **旺衰档位改变** | **0 张（0%）** |
| **用神改变** | **34 张（28.3%）** |
| 流通度 \|Δ\| | 中位 0.010，最大 0.130 |

读法很清楚：

> **旺衰不受影响，用神受影响。**

旺衰是五档的粗判，这一层那点缩放跨不过档界；
而用神的取舍常常在两个相近的候选之间摇摆，这一层的改写足以把天平拨过去。

所以这个开关**不是「要不要更精确」，而是「用神由谁定」**——
交给这一层先改一道，还是全部交给传导层的收敛。

这个数字值得你知道：如果你在两个不同的工具上得到了不同的用神，
很可能差别就在这里，而不是谁算错了。

---

## 5.5 这一章最该记住的

1. **六种关系有固定的结算次序**，范围大者优先。
2. **争合、合而逢冲要裁决**，裁决依据必须留在推导链里。
3. **「察」与「改」是两件事。** 混为一谈会让半条链路静默失效。
4. **关掉「改」：旺衰不变，用神有 28% 会变。** 这是实测，不是估计。

下一章进入真正的「断」—— 旺衰、用神、格局、六亲。
那是这套系统第一次给出带有判断性质的话，
也是本项目给结论配置信度与替代读法的起点。
