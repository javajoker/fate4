## 排盘相关

| 术语 | 意思 |
| **八字** | 四柱的八个字。年月日时各一干一支（[2](02-干支与五行.md)） |
| **胎元** | 由月柱推出的一组干支，传统上代表「来处」（[3](03-排盘.md)） |
| **地支** | 子丑寅卯辰巳午未申酉戌亥，十二个（[2](02-干支与五行.md)） |
| **节 / 气** | 二十四节气分两类。**分月用节**，气另有用处（[3](03-排盘.md)） |
| **命宫** | 由月与时推出的一个地支，代表整个人的处境（[3](03-排盘.md)） |
| **纳音** | 六十甲子各配一个意象名，如「海中金」。叙述用（[3](03-排盘.md)） |
| **起运** | 大运从几岁开始换。由出生到最近一个节的距离定，三天折一岁（[3](03-排盘.md)） |
| **日主 / 日元** | 日柱的天干，代表命主本人（[2](02-干支与五行.md)） |
| **四柱** | 年柱、月柱、日柱、时柱（[1](01-它在算什么.md)） |
| **四墓库** | 辰戌丑未，各藏三个天干。被冲被刑则「开」（[5](05-结构.md)） |
| **天干** | 甲乙丙丁戊己庚辛壬癸，十个（[2](02-干支与五行.md)） |
| **旬空** | 当前这一旬里缺掉的那两个地支（[3](03-排盘.md)） |
| **真太阳时** | 那个地点的太阳位置对应的时间。= 钟表时 + 经度差 + 均时差 − 夏令时（[3](03-排盘.md)） |
| **藏干** | 地支里「藏」着的一到三个天干，分本气、中气、余气（[2](02-干支与五行.md)） |

## 本项目特有的说法

| 说法 | 意思 |
| **察 / 改** | 结构层的两件事：认出发生了什么 / 据此改写权重。可以分开（[5](05-结构.md)） |
| **措辞守卫** | 输出前逐句扫描，拦断言的**形状**而不是词（[11](11-它算不出什么.md)） |
| **人话层** | 把判定枚举换成平常话的那一层。规矩比术语层**更严**（[10](10-怎么用.md)） |
| **四家合参** | 四柱流日 ∥ 六爻 ∥ 六壬 ∥ 奇门。**只对照，不合成**（[9](09-问事.md)） |
| **推导链** | 每条结论旁边可展开的那段东西。没有它的结论不允许进报告（[6](06-断论.md)） |
| **参数指纹** | 整份参数的哈希。两份报告指纹相同才可比（[12](12-自己调参.md)） |
| **置信度 / 替代读法** | 结论离阈值太近时，必须同时给出另一种读法（[6](06-断论.md)） |

## 三句最该记住的话

> **张力大不等于会出事，张力小也不等于太平。**（[11](11-它算不出什么.md)）

> **θ 是「取多少条」的旋钮，不是显著性水平。**（[7](07-时间.md)）

> **一致不等于互证** —— 四家都是同一组干支的确定性函数。（[9](09-问事.md)）
