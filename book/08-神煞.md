# 8 · 神煞

天乙贵人、桃花、华盖、驿马、羊刃、血刃、孤辰寡宿…… 这些名字是八字里
最有画面感的一层，也是最容易被当成算命结论的一层。

本项目实现了 **36 条**，但给它们划了一条很硬的线。

---

## 8.1 神煞是什么

每一条神煞都是一个**查表规则**：由某一柱的干或支，查出另一个干支；
盘里若有，就算「带」这个神煞。

```
天乙贵人   由日干查     甲戊庚日 → 丑、未
桃花       由年支或日支查  寅午戌 → 卯
驿马       由年支或日支查  申子辰 → 寅
```

规则本身是确定的，查出来对不对可以验证。本项目对每条神煞
**同时实现推导式与查表式，并断言两者一致** —— 起例写错了，
这条测试会当场发现。

---

## 8.2 这条硬线：神煞不进权重

**一条神煞都不参与力量计算。**

它们不改变任何载体的权重，不改变旺衰，不改变用神，不改变曲线。

### 为什么

因为神煞是**另一套东西**。前面几章那条管线（配重 → 传导 → 断论）
是一个连续量的模型；神煞是一组离散的标签。把标签折成分数加进去，
需要一个「天乙贵人值多少分」的数 —— 而那个数不存在于任何典籍，
只能是编的。

一旦编了，它就会以一个有精度外观的方式影响最终结论，
而读者无从知道那是编的。

> 这一条有测试把守：**换一套神煞开关，权重类的曲线节点逐字不变**。
> 如果哪天有人把神煞接进了权重，这条测试会红。

### 那它们干什么用

两件事：

| | |
| **叙述素材** | 给结构描述配上具体的所指。「金舆」传统上与车马出行相联系 |
| **状态标记** | 这一刻它是否被引动（被冲、被合、值年） |

第二件有用处：报告里说「今年 X 宫的某某被引动」，
配合那条曲线在同一时段的变化，读者能看到「这个变化传统上挂在哪一类事上」。

---

## 8.3 「指事」是什么，不是什么

本项目把神煞的叙述用法叫**指事** —— 它指向哪一类事。

```
金舆   → 车马、出行一类
桃花   → 人缘、情感往来一类
华盖   → 独处、钻研、冷门一类
驿马   → 迁动、外出一类
```

必须说清楚的是：

> **指事说的是「这个符号传统上与哪类事相联系」，不是「会发生什么事」。**

「金舆被引动」不等于「你今年会出远门」。它等于「传统上会把这一时段的
变化挂在出行这一类上」。这两句话的差别就是这本书反复在守的那条线。

界面上每一条指事旁边都带着这句框定，不是可选的装饰。

---

## 8.4 凶煞怎么处理

有些神煞的名字很吓人：血刃、劫煞、亡神、孤辰寡宿。

本项目的处理：

- **照实实现，不删。** 删掉等于改写传统，那不是本项目的位置。
- **不作断语。** 报告里不会出现「你带血刃，要小心意外」这样的话。
- **出现时必须带框定。** 写法是「传统上此煞与灾厄一类语汇相联系」，
  而不是「此煞主灾厄」。

这条是由[措辞守卫](11-它算不出什么.md)强制的：
一个孤零零的神煞名出现在词汇表里没问题，
但它出现在**正文**里却没带框定语，输出会被直接拦下来。

---

## 8.5 这一章最该记住的

1. **36 条神煞，一条都不进权重。** 有测试锁住。
2. **它们是叙述素材与状态标记**，不是结论。
3. **指事说的是「与哪类事相联系」，不是「会发生什么」。**
4. **凶煞照实实现，但不作断语，且必须带传统框定语。**
