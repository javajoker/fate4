# 07 · 神煞

## 0. 神煞在本系统中的定位

**神煞不参与权重计算。**

L1–L3 是力量模型，神煞是**符号层**。把神煞折算成分数加进旺衰，是把两套不同来源、不同抽象层级的东西混在一起，必然产出既不符合古法也不符合量化的结果。

神煞的作用有三：

1. **叙述素材** —— 报告中的意象与措辞来源
2. **应期触发器** —— 驿马逢冲、桃花逢合等，是 [08-temporal](08-temporal.md) 规则引擎的输入
3. **宫位定性** —— 落在哪一宫，就修饰那一宫的六亲解读

**唯二例外**：`禄` 与 `羊刃`。它们本质是十二长生的临官位与帝旺位，已经通过通根评分进入 L4 的力量模型（见 [01-foundations](01-foundations.md) §9）。在神煞层它们只作展示，**不得二次计入**。

```yaml
shensha:
  primaryBase: day          # day | year   —— 日干/日支为主（现代通行）

```

同一个神煞可能同时以日为基和以年为基命中不同的支。两份都保留，报告中分列。

## 8. 神煞的状态修饰

同一个神煞，落在不同状态的支上，语义相反。这层修饰**必须计算**，否则神煞只是一堆标签。

| 修饰 | 判定依据（来自 L2 / L3） | 语义方向 |
| --- | --- | --- |
| `逢冲` | 该支参与了六冲 | 吉神被冲→受损；凶神被冲→动而应事（驿马尤甚） |
| `逢合` | 该支参与了合 | 吉神被合→合住不发；凶神被合→制住（桃花逢合主感情事） |
| `逢刑` | 参与三刑 | 一律加重负面色彩 |
| `落空亡` | 在日柱或年柱旬空内 | 吉神落空→大打折扣；凶神落空→反解 |
| `坐旺` | 宿主支的最终权重 ≥ 场均 × 1.3 | 神煞力量增强 |
| `坐衰` | 宿主支的最终权重 ≤ 场均 × 0.5 | 神煞力量减弱 |
| `重见` | 同一神煞在多柱出现 | 加重，但吉神重见亦可能过犹不及 |

`坐旺 / 坐衰` 是权重模型对符号层的**唯一单向输出**——力量影响神煞的解读强度，神煞不反过来影响力量。这个方向不可逆转。

宿主没有载体时（命宫，以及未计入配重的胎元）**不论坐旺坐衰**。权重为 0 会被判成「坐衰」，
而那不是衰，是压根不参与力量层。

### 8.1 修饰必须落到「层」与「字」，不能只落到「柱」

判据一栏写的是「该**支**参与了六冲 / 合」。实现上极容易退化成「该**柱**参与了」——
两者差得很远：年干的一个天干五合，会把坐在**年支**上的每一个神煞都标成「逢合」，
而天干合根本没碰到地支。

实测这条退化的后果（240 个盘年）：天乙贵人出现 360 次，其中 299 次被标为「逢合」、
272 次「逢刑」。修饰一旦近乎恒真，它就不再是修饰。更糟的是连锁反应——
`effectiveTone` 先判合、后判冲，虚假的「逢合」会把真正的「逢冲」整个盖掉，
于是应期层里四条依赖「逢冲」的规则**永不触发**。

正确的判据是三条同时成立：

1. 事件的 `pillars` 含该柱
2. 事件的**层**与神煞所在的层一致（`ganhe` / `ganchong` 作用于天干，其余作用于地支）
3. 事件的 `branches` / `stems` 含神煞所坐的那个字

## 9. 数据结构

```ts
interface ShenshaHit {
  readonly name: string;                    // '天乙贵人'
  readonly category: 'noble' | 'peach' | 'travel' | 'canopy' | 'blade'
                   | 'solitary' | 'punish' | 'void' | 'other';
  readonly base: 'dayStem' | 'yearStem' | 'dayBranch' | 'yearBranch'
               | 'monthBranch' | 'pillar' | 'combination';
  readonly landsOn: Position;               // 落在哪一柱哪一层
  readonly palace: PalaceName;              // 对应宫位（祖上/父母/配偶/子女…）
  readonly modifiers: ShenshaModifier[];    // §8
  readonly hostWeight: number;              // 宿主支的最终权重（供 坐旺/坐衰 判定）
  readonly polarity: 'auspicious' | 'inauspicious' | 'neutral';
  readonly narrativeTags: string[];         // 供 L6 取文案
}
```

**`palace` 是必填字段。**「有华盖」是废话，「华盖在时支子女宫且逢空」才是一条可读的信息。任何不带宫位的神煞输出都视为实现缺陷。

## 9.1 扫描范围

`shensha.scanTargets` 的默认值列了 `luck` 与 `annual`。这不是可选项——
**「流年驿马」「流年桃花」正是最典型的应期**，不扫流年支等于把应期层的一半判据抽掉。

首版实现只铺了四本命柱，参数形同虚设。实测后果：240 个盘年里，
驿马与桃花的出现次数恒等于它们在本命盘里的次数——流年支换过 60 轮却从未被看见，
羊刃一次都没出现过，四条依赖流年神煞的应期规则触发率为 0。

### 9.2 每个落点必须有自己的位置，不得冒充别人的

同一个错犯了三次，形态一模一样：**把一个没有 `PillarKind` 的落点塞进某个现成的 kind**。
产出的神煞名字都对，宫位却错了 —— 而宫位恰恰是神煞唯一有信息量的那一半。

| 落点 | 曾被塞进 | 后果 |
| --- | --- | --- |
| 命宫 | `taiyuan` | 命宫的天乙被报成「胎元」，宫位错成「外部」 |
| 胎元 | 无专属宫位 | 八个神煞全挤在「外部」下，读者无从分辨来自何处 |
| 流月 | 直接把本命月柱替换掉 | 流月的神煞被标成「门户宫」，即本命的父母/门户宫 |

三者都不参与配重（没有载体、不入生克），但都是真实的落点。
故 `ShenshaTarget = PillarKind | "mingGong" | "fleetingMonth"`，
并各自映射到「命宫」「胎元」「流月」三个宫位名。

`landsOn.pillar` 与 `palace` 一一对应，由 `test/shensha.spec.ts` 逐条断言不得串位。

### 9.3 「空亡」不以自身的定义充当自身的修饰

空亡这个神煞的定义就是落在旬空里，于是它必然带上「落空亡」修饰，
经 `effectiveTone` 又必然得出「凶神落空，反得其解」—— 一个恒真的自指。
扫描时须把它自己的这一条剔除。

## 10. 时间层的神煞

流月与流日**不重算权重**，但**要算神煞**（用户需求第 6、7 条）。

```
monthShensha = 以本命日干/日支为基，扫描当月月柱的干支
dayShensha   = 同上，扫描当日日柱
```

再叠加与命局的引动关系（冲合刑害），构成当月/当日的事件集。详见 [08-temporal](08-temporal.md)。

## 11. 措辞约束

神煞名称自带强烈情绪色彩（`十恶大败`、`灾煞`、`亡神`、`孤鸾`）。L6 生成叙述时：

- **不得**直接以神煞名作断语（「你有孤鸾煞，婚姻不顺」是禁止的输出形态）
- **必须**先经 §8 的状态修饰，再结合宫星同参的结论
- **必须**在措辞上保留主体性：描述倾向与张力，不预言结果

具体约束见 [09-report](09-report.md) §6。

## 10. 神煞在新层里的角色（P12–P15）

[12-persona-curves-nodes](12-persona-curves-nodes.md) 给神煞两项新职责，
**方向仍然单向 —— 神煞不进入力量模型**：

### 10.1 解释基础盘的结论：强在哪里、为什么强

```
对人格层的每条结论 c（主导十神、过旺五行、某宫得力…）：
  1. 找出支撑 c 的载体集合 S
  2. 取落在 S 所在宫位上的神煞
  3. tone 为 strengthened / activated 者优先，
     narrativeTags 与 c 的特质词有交集者次之，其余按 hostWeight 降序
```

「**为什么强**」的答案来自**力量层**（通根、司令、透干、得生）；
神煞只补「传统上此处还被赋予什么含义」。二者在叙述中分句，不混。

### 10.2 解释曲线上的拐点：异常的理由

节点由权重曲线检出，**检出之后**才去找神煞：

```
在穿越区间的进入点 t_in 前后一个月内，取即时盘的符号层，筛出：
  · tone 为 activated（被引动）者
  · 该窗口内牵动大运或流年的结构事件
  · 该窗口内触发的应期规则
按「与 t_in 的时间距离」升序 —— 最靠近进入点的，最像是引发它的
```

> 规格初稿另列了两条判据：「落在本节点涉及宫位上者」与「域标签与本节点的域重叠者」。
> **实现时未采用**，因为二者都是**静态**匹配 —— 本命神煞落在哪个宫、带哪些域标签，
> 是基础盘就定下的，六十年里每一个时点都成立。把它们列为「这一刻变化的理由」，
> 等于给每条节点都配上同一批理由，而恒真的理由不解释任何事。
> 保留的三条都要求**该时刻发生了什么**。

叙述的形状固定为：**结构事实在前，传统语汇在后，中间不加因果连接词。**

> 2031 年 3 月起，官杀曲线进入偏离区（z = 2.3，持续至 2033 年 8 月，
> 2032 年 5 月最甚 z = 3.1）。同期流年支冲日支，配偶宫的驿马被引动，
> 大运支与本命月支三合成局。传统上这三项与变动、迁移一类语汇相联系。

末句不写「所以」「因此」「导致」—— 神煞是**素材**，不是**因果链的一环**。
