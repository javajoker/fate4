# 17 · 紫微斗数

> 面向读者的讲法在《测天，还是约定》[第 13 章](../book-compare/13-紫微的技法.md)。
> 本篇是实现规格。

---

## 1. 它在管线上的位置

与星盘一样，**不在 L0–L6 的管线上**。它只共用 `chart/lunar.ts` 与 `ganzhi/`。

```
BirthInput ─┬─ buildChart ──────→ L0…L6（四柱）
            ├─ skyChart ────────→ 星盘
            └─ buildZiweiChart ─→ 紫微
```

---

## 2. ⚠️ 年干支取农历年，不是立春年

这是本模块与四柱**最要紧的一处分歧**：

| | 岁首 |
| --- | --- |
| 四柱年柱 | **立春** |
| 紫微年干支 | **正月初一** |

两者差十天到一个多月。生在这两个日子之间的人，两套给出的年干支不是同一个 ——
而年干在紫微里决定四化、禄存、擎羊陀罗、天魁天钺与每一宫的宫干。
**取错一个，盘上一大半东西跟着错。**

`ZiweiChart` 带 `yearBasis` 与 `agreesWithSolarYear`；
传入 `solarYearStem` 即比对，不一致时出警告。
测试用 1990-01-29（1990 正月初一 1/27、立春 2/4 之间）锁住。

---

## 3. 输入只有五样

```
农历年干支 · 农历月 · 农历日 · 时辰 · 性别
```

不查星历，不看节气，**不要地点**。这是 `compare/systems.ts` 把紫微归入
「历法派生」而非「实测天体」的直接依据 —— 不是印象，是起法本身。

但不把结论推过头：紫微**自己**不算天象，它吃的农历是实测的
（定朔要真算合朔，置闰要看中气），故它不是「纯约定」那一档。

时辰由**当地钟表时**定，不做真太阳时校正 ——
紫微的传统起法不涉及经度，替它加一道四柱才有的校正是拿一套的规矩改另一套。

### 流派都在参数里

`Params.ziwei`：

| | |
| --- | --- |
| `leapMonth` | 闰月归属。只实现 `asIs`（归本月）；`splitHalf` 是真实存在的另一派，条目留着是路线图，设置即报错并说明 |
| `huoLing` | 火星铃星起例。只实现 `conventional` |
| `trueSolarTimeHour` | **[硬约束] 恒为 `false`**，设为 true 即报错 |

这几样改的是**盘本身**，故在参数里而不是函数参数里 ——
它们必须进参数指纹，否则两张用不同取法排出来的盘会得到同一个指纹。

## 4. 起法

### 4.1 十二宫（`palaces.ts`）

```
命宫：自寅起正月，顺数至生月；再自该宫起子时，逆数至生时
身宫：同样起算，但顺数至生时
```

两者只差最后一步的方向 —— 故**子时生人命身同宫**，可做自检。
自命宫**逆行**安十二宫。

### 4.2 五行局

命宫天干由年干起五虎遁（**直接复用四柱的 `monthStemOf`**，不另写一份），
地支即命宫所在；取该干支纳音的五行，得水二、木三、金四、土五、火六。

局数**只服务于定紫微一步**，不参与别的判断。

### 4.3 紫微星（`stars.ts`）

> 以局数除日数。整除则商即步数；不整除则借数凑整，
> 借数为偶则再进借数，为奇则退借数。

它在把 1–30 日**均匀摊到十二宫**，借数的奇偶进退是摊不满时的回落 ——
**取整的补偿项，不是玄学**。

### 4.4 其余十三主星

天府与紫微关于**寅申轴对称**，由对称算出，不另立表（对称是对合，可自检）。

```
紫微系（逆行）  紫微 0　天机 −1　太阳 −3　武曲 −4　天同 −5　廉贞 −8
天府系（顺行）  天府 0　太阴 +1　贪狼 +2　巨门 +3　天相 +4　天梁 +5　七杀 +6　破军 +10
```

### 4.5 辅星与四化

三对吉星用三个不同的输入：左辅右弼（农历月）、文昌文曲（时辰）、
天魁天钺（年干）—— **这是这套体系的接缝**，对研究者比规则本身更有信息量。

禄存由年干定，**擎羊在前一位、陀罗在后一位**，三者恒相邻（可自检）。

四化不摆新星，给盘上已有的四颗星各加一个标记。
它是**年干与星的交互**，不是星的属性。

### 4.6 大限

阳男阴女顺行，阴男阳女逆行；自命宫起每宫十年，首限起于局数那一岁。
**性别只改大限方向，不改任何一颗星的落位** —— 测试逐宫比对锁住。

## 5. 解读（`reading.ts`）

四条**全部可由落位推出**，不另引一张表：

| | |
| --- | --- |
| **三方四正** | 本宫、对宫（+6）、三合二宫（±4），四宫同看 |
| **空宫借星** | 本宫无主星则借对宫 |
| **四化落宫** | 并标出是否在命宫三方四正内 |
| **格局** | 只收由落位直接判定、各家名目一致的几种 |

对命宫而言，三合的两宫恰是**财帛与官禄** —— 不是巧合，
是十二宫逆行排布的直接后果（财帛逆四位、官禄逆八位，而逆四逆八正是 ±4）。

### 一条算得出来的结构性断言

**杀破狼在三方四正里只能见三颗或一颗，绝不会是两颗。**

七杀、破军、贪狼在天府系里分别是 +6、+10、+2，两两相差四宫 ——
恒在同一条三合线 {k, k+4, k+8} 上。而命宫的三方四正是另一条三合线
{m, m+4, m+8} 加对宫 m+6。于是只有两种命中方式：
命宫那条线就是杀破狼线（三颗），或对宫落在杀破狼线上（一颗）。

写成测试，并带反向对照（样本里三种命中数都出现过）。

### ⚠️ 不收星曜庙旺表

十四主星 × 十二宫 = **168 格**。凭记忆转录的风险比调候 120 格更大，
而结构性检查对它几乎无能为力：一格记错看不出来，
却会悄悄改变对某颗星的强弱判断。

**这是一个真实的缺口，不是设计上的取舍。** 收齐它需要一个底本。
代码注释、`notes`、界面、书里四处都这么写。

### 不出断语

「命宫坐七杀」是事实陈述；「主性格刚毅」「宜从事某行」是另一回事 ——
那一层没有可判定的规则，与现代占星那一层同理。全部产出过措辞守卫。

## 6. 状态空间（穷举，非估计）

```
输入基数   60 × 12 × 30 × 12 × 2 = 518,400
不同的盘   34,560
坍缩比     恰好 15 个输入 → 1 张盘
```

坍缩主要来自「日 → 紫微落点」是多对一：一局之内三十天只摊到十二宫。
性别又贡献一个因子 2（只改大限方向）。

**一个穷举才看得出来的结构**：`distinctCharts === distinctStarLayouts` ——
星曜布局**唯一决定**命宫位置与年干四化，把那两样加进比对的键，
一张盘都没有多分出来。

> ⚠️ 这个数属于**本实现所收星曜**。收更多杂曜会让盘更易区分。
> 写在 `ZiweiStateSpace.note` 里，不只写在文档。

另：输入基数 518,400 与四柱的状态数相同，而**两者的因子不是同一批** ——
数字相同不说明任何事。

## 7. 不变量

1. 子时生人命身同宫。
2. 十二宫不重不漏；兄弟宫恒在命宫逆一位。
3. 命宫干支恒同奇偶（否则纳音取错，抛错而非凑合）。
4. 天府与紫微的对称是对合。
5. 擎羊陀罗恒夹禄存；天马恒在四马地。
6. 四化恒四颗、不重星；十个年干的表都齐。
7. 性别不改任何一颗星的落位。
8. 杀破狼在三方四正里只能见 0、1 或 3 颗。
