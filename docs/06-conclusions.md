# 06 · L4 断论层

L3 收敛后得到一组权重。L4 把权重翻译成命理判定。**这是最后一个确定性层**——所有判定都是阈值与查表，无自由发挥。叙述生成在 L6，不在这里。

每个判定产出 `Verdict<T>`，含 `value` / `confidence` / `derivation` / `alternatives`。

---

## 1. 十神向量

以日主 `dm`（日柱天干载体）为基准，把 10 维天干向量映射为 10 维十神向量。映射表见 [01-foundations](01-foundations.md) §5。

```ts
type TenGodVector = Record<TenGod, number>;   // 权重之和，非计数
```

**日主自身的权重不计入比肩**，单列为 `dayMasterWeight`。这是常见实现错误：把日主算进比肩会让每个盘都显得身强。

聚合：

```
同党 = dayMasterWeight + 比肩 + 劫财 + 正印 + 偏印
异党 = 食神 + 伤官 + 正财 + 偏财 + 正官 + 七杀
```

---

## 2. 通根评分

在旺衰判定前先算日主的根。

```
rootScore = Σ over 所有地支 b:
              max over b 的藏干 h where elem(h) == elem(dm):
                rootCoef(h 在 b 中的角色) × (b 的距离系数)
```

`rootCoef` 见 [01-foundations](01-foundations.md) §9：禄刃 1.00 · 长生 0.70 · 库根 0.50 · 余气 0.30。

**日支的根权重最高**（距离 1.00），年支最低。同一支只取最强的一个根，不累加。

`rootScore == 0` 是从格的必要条件之一。

---

## 3. 旺衰判定

```
r = 同党 / (同党 + 异党)
```

| `r` | 判定 | 标签 |
| --- | --- | --- |
| `≥ 0.70` | 极旺 | `VERY_STRONG` — 专旺格候选 |
| `[0.55, 0.70)` | 身旺 | `STRONG` |
| `[0.45, 0.55)` | 中和 | `BALANCED` |
| `[0.30, 0.45)` | 身弱 | `WEAK` |
| `< 0.30` | 极弱 | `VERY_WEAK` — 从格候选 |

```yaml
conclusion.strengthBands:
  veryStrong: 0.70
  strong:     0.55
  balancedLow: 0.45
  weak:       0.30
```

**置信度**：`r` 距最近边界越远，`confidence` 越高。

```
d = min(|r − 每个相邻阈值|)
confidence = clamp(d / 0.05, 0.3, 1.0)
```

`r = 0.548` 时 `confidence ≈ 0.3`，报告必须写「接近中和与身旺的临界，两种取用皆需参考」，并在 `alternatives` 里给出另一种判定下的用神。

**这一条是本系统与市面工具的主要区别。**临界盘就是临界盘，不该被强行归类。

## 4. 特殊格局判定

按顺序检测，先命中者胜出。

### 4.1 从格

**门槛（全部满足）**：

```
r < 0.30
rootScore == 0
月令本气的十神 ∉ {比肩, 劫财, 正印, 偏印}
无有力的印星生身（印星权重 < congge.yinThreshold，默认 25）
```

分型（取异党中权重最高的一组）：

| 型 | 条件 |
| --- | --- |
| 从财格 | 财星（正财+偏财）最旺 |
| 从杀格 | 七杀最旺 |
| 从官格 | 正官最旺 |
| 从儿格 | 食伤最旺 |
| 从势格 | 财、官杀、食伤三者无一超过其余之和的 1.3 倍 |

### 4.2 专旺格

```
r ≥ 0.78  且  异党中无一项 ≥ specialGe.suppressThreshold（默认 40）
```

| 格 | 日主五行 | 传统名 |
| --- | --- | --- |
| 曲直仁寿格 | 木 | 曲直 |
| 炎上格 | 火 | 炎上 |
| 稼穑格 | 土 | 稼穑 |
| 从革格 | 金 | 从革 |
| 润下格 | 水 | 润下 |

### 4.3 化气格

```
日主与月干或时干构成天干五合
且 L2 判定为 TRANSFORMED（化成）
```

化神即新的「日主五行」，用神取生扶化神者。

⚠️ 化气格的实务争议极大（成格条件严苛，误判率高）。默认 `conclusion.enableHuaqi = true` 但 `confidence` 上限设为 `0.6`，报告中必须并列常规扶抑的解读。

### 4.4 未命中

回到 §3 的常规五档，走扶抑路线。

## 5. 用神选取

优先级：`调候（极端时）→ 扶抑 → 通关 → 病药`

### 5.1 调候（气候优先）

**触发条件**（可计算，不依赖查表）：

```
寒燥指数 = (金权重 + 水权重) / 总权重
温燥指数 = (木权重 + 火权重) / 总权重

极寒: 月支 ∈ {亥,子,丑} 且 火权重/总权重 < tiaohou.fireFloor      # 0.08
极燥: 月支 ∈ {巳,午,未} 且 水权重/总权重 < tiaohou.waterFloor     # 0.08
```

命中则 `调候用神` 强制优先：极寒取火（丙优于丁）、极燥取水（壬优于癸）。

> ⚠️ **待校准**：《穷通宝鉴》的完整调候表是 10 日干 × 12 月支 = 120 格，含主用神与辅用神。
> 本文档**不列出该表**——凭记忆转录 120 格必然出错，而错误的调候表比没有更糟。
> 实现时须从《穷通宝鉴》（或《栏江网》）逐格转录为 `data/tiaohou.json`，并由两个独立来源交叉校对。
> 在该表就位前，引擎使用上述可计算的极端气候规则作为降级方案，且在输出中标记 `tiaohouSource: 'heuristic'`。
>
> 可靠的一般原则（可先行实现）：
> - 冬月（亥子丑）生，寒木寒金寒水皆喜丙火解冻；调候之丙不可被壬水困
> - 夏月（巳午未）生，燥土燥木皆喜壬癸润泽
> - 春月（寅卯辰）木旺，喜庚金修剪、丙火发荣
> - 秋月（申酉戌）金旺，木宜丁火炼金，水宜戊土制之以免泛滥

### 5.2 扶抑

| 日主状态 | 用神 | 忌神 |
| --- | --- | --- |
| `VERY_STRONG` / `STRONG` | 食伤（泄）· 财（耗）· 官杀（克）中，取当前权重最合适者 | 印 · 比劫 |
| `WEAK` / `VERY_WEAK`（未从） | 印（生）· 比劫（帮） | 财 · 官杀 · 食伤 |
| `BALANCED` | 取全局最弱的一环补之，或取通关之神 | 视具体 |
| 从格 | 顺从所从之神及其生者 | 逆之者（尤其印比） |
| 专旺格 | 比劫 · 印 · 食伤（顺其势） | 官杀（逆其势） |

**身旺时三选一的规则**（避免机械取「最强的那个」）：

```
候选 = {食伤, 财, 官杀}
score(候选) = 该组当前权重 × 该组在流通链上的通畅度
通畅度 = 该组被其生者的权重 / (该组被其克者的权重 + 1)
取 score 最高者为用神；若最高者权重 < 15，判为「用神无力」，标记 needsLuckSupport
```

「用神无力」是一个重要且经常被忽略的状态：用神选对了但盘中不存在，只能等大运送来。

### 5.3 通关

两组势均力敌且相克时（如财旺与比劫旺相持），取能化解的中间五行。

```
触发: 存在 A, B 使 elem(A) 克 elem(B)，且 |W_A − W_B| / max(W_A,W_B) < 0.20，且 W_A + W_B > 总权重 × 0.45
用神 = 使 A 生 M 生 B 的中间五行 M
```

### 5.4 病药

盘中某一忌神独强且直接损害用神 → 该忌神为「病」，能制它的为「药」。

```
病 = argmax over 忌神组 (权重)，且该组对用神的累计克流量 > bingyao.damageThreshold
药 = 克「病」的五行
```

### 5.4b 调候与扶抑方向相反时，必须并列

一个真实且常见的情形：日主判为**身弱**，而调候却取**克身之神**。

工作例（庚午 辛巳 丁丑 丁未）即如此 —— 丁火生巳月，火占全盘逾半，
却因土金厚重而党势仅 0.4496（身弱）；同时水仅占 4.8%，触发极燥调候，取水。
扶抑当取木火生扶，调候却取水，两条路**方向相反**。

这不是矛盾，是调候与扶抑的固有张力。处理方式：

- 调候仍按优先级胜出，作为 `value`
- 扶抑的结论写入 `alternatives`，并注明「方向相反」
- `confidence` 由 0.55 再降至 **0.45**，从而触发「低置信度必须给出替代解读」的不变量

把这种张力藏起来、只报一个用神，是这一层最容易犯也最难被发现的错误 ——
输出看起来干净利落，实则丢掉了盘中最要紧的信息。

### 5.5 输出

```ts
interface YongshenVerdict {
  method: 'tiaohou' | 'fuyi' | 'tongguan' | 'bingyao';
  primary: Element;
  secondary?: Element;
  xishen: Element[];      // 喜神：生用神者
  jishen: Element[];      // 忌神
  choushen: Element[];    // 仇神：生忌神者
  xianshen: Element[];    // 闲神
  strength: number;       // 用神在盘中的当前权重
  needsLuckSupport: boolean;
  confidence: number;
  alternatives: YongshenVerdict[];
}
```

## 6. 格局（月令取格）

按序判定：

1. 月支**本气**在年干 / 月干 / 时干透出 → 以该天干的十神定格
2. 本气不透，**中气**透 → 中气定格
3. 中气不透，**余气**透 → 余气定格
4. 皆不透 → 取月支本气的十神为格
5. 若所定十神为**比肩** → 建禄格；为**劫财** → 阳干作月刃格，阴干作月劫格

**八格**：正官 · 七杀 · 正财 · 偏财 · 正印 · 偏印 · 食神 · 伤官（+ 建禄 / 月刃）

**顺用逆用**：

| 类 | 十神 | 取用方向 |
| --- | --- | --- |
| 四吉神 | 正官 · 财 · 正印 · 食神 | **顺用**：生之、护之 |
| 四凶神 | 七杀 · 伤官 · 偏印 · 羊刃 | **逆用**：制之、化之 |

**相神**：使格局成立的关键之神。

| 格 | 成格之相神 | 败格 |
| --- | --- | --- |
| 正官格 | 财生官、印护官 | 伤官见官、刑冲官星 |
| 七杀格 | 食神制杀、印化杀、羊刃合杀 | 财党杀而无制 |
| 正财格 | 食伤生财、身强任财 | 比劫夺财、身弱财重 |
| 正印格 | 官杀生印 | 财星坏印 |
| 食神格 | 身强食旺生财 | 枭神夺食 |
| 伤官格 | 伤官配印、伤官生财 | 伤官见官（除伤官格喜官者） |
| 建禄 / 月刃 | 官杀制、财官并透 | 无制而群比争财 |

`格局` 与 `用神` 是**两条独立的判定线**，可能给出不同的取用建议。本系统**同时输出两者**，并在不一致时于报告中并列，不做强行统一。子平格局法与旺衰扶抑法本就是两个流派，人为调和只会产出两边都不认的结论。

### 7.3 宫星同参

每个六亲的判定必须**同时**看两处：

```
宫的状态 = 该柱地支（或天干）的最终权重、是否受冲刑、是否空亡、坐何十神
星的状态 = 该六亲星的最终权重、是否透干、是否受制、是否入墓
```

四象限：

| | 星旺 | 星弱 |
| --- | --- | --- |
| **宫吉** | 最佳，该六亲缘厚且得力 | 缘分在而助力薄 |
| **宫凶** | 得力但过程有波折 | 该六亲较为疏远或早离 |

**只看星不看宫，或只看宫不看星，都是残缺的读法。**引擎必须两者都算，报告必须两者都列。

### 7.5 流派开关随盘声明

`conclusion` 段有四个流派开关，**结论会因它们分叉**，故必须随盘输出 `schoolsUsed`：

| 开关 | 影响 |
| --- | --- |
| `changshengSchool` | 改变长生排布 → 根的**等级** → 通根评分 → 旺衰 |
| `earthChangsheng` | 同上，专对戊己 |
| `yongshen.tiaohou.source` | `heuristic` 表示《穷通宝鉴》表未就位，走降级规则 |
| `femaleChildStarVariant` | 女命子女星的男女分配 |

⚠️ **换流派不必然改变某一盘的总分。**丁火在午/巳/未三支下，阳顺阴逆与阴阳同生同死
恰好给出相同等级（午：临官 ↔ 帝旺，皆归 `luRen`），故工作例的通根评分不变。
这不是开关失效 —— 要看分叉须直接查长生表：乙木在亥，阳顺阴逆为「死」只作余气根，
阴阳同生同死为「长生」。

测试须据此写。若按「换流派必改变评分」的直觉去断言，会得到一条失败的测试，
进而诱使人去「修」一个正确的实现。

## 8. 五行流通评估

除旺衰外，另给三个全局指标：

| 指标 | 计算 | 含义 |
| --- | --- | --- |
| `vitality` | 来自 L3 | 内耗程度 |
| `circulation` | 生流量总和 / (生流量 + 克流量) | 五行是否流通有情 |
| `evenness` | 五行权重向量的归一化熵，`H / ln 5` | 五行是否均衡（越接近 1 越均匀） |

`evenness` 高不等于命好。偏枯（`evenness` 低）而成格成局者不在少数。此指标只用于描述结构，报告措辞须避免价值判断。

## 10. L4 不变量

1. `同党 + 异党 == Σ 全部载体权重`（误差 < 1e-9）。
2. `r ∈ [0, 1]`。
3. 从格与专旺格**互斥**。
4. 若 `rootScore > 0`，`specialPattern` 不得为任何从格。
5. 每个 `Verdict` 的 `derivation` 非空。
6. `confidence < 0.5` 时 `alternatives` 必须非空——低置信度的判定必须给出另一种可能。
