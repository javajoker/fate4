## 1. 先厘清四条边界

### 1.0 「不再重新计算基础盘」的准确含义

你写的是：「基础盘是后续计算基准，不再重新计算基础盘。基于基础盘计算新的大运流年时间命盘。」

这句话包含两个可能的读法，**第一个成立，第二个不成立**，必须分开：

| 读法 | 是否成立 | 说明 |
| -- | -- | -- |
| **基础盘只算一次，冻结为定值，一切时点结果都以它为参照** | ✅ **完全照办** | 见 §2.0 |
| **即时盘不再跑全局的结构与生克，只在基础盘上叠加大运流年** | ❌ **做不到，也不该做** | 见下 |

第二个读法为什么不成立 —— 两个具体的反例：

**其一，三合需要全部地支同时在场才看得见。**
本命有寅、午两支，本身只成半合。流年来一个戌，寅午戌三合火局立成，
化神之火大增、非化神之支大减。这个判定**必须**在「本命四支 + 大运支 + 流年支」
的完整支集上重新检测 —— 只看基础盘的结果，永远看不到这个局。

**其二，冲的裁决依赖相对权重，而权重在运内是连续变化的。**
`structure/apply.ts` 中冲的损耗分三档，按强弱比 `ratio` 判：

```
ratio ≥ 2.50  → 拔根，弱方损 75%
ratio ≥ 1.20  → 强方损 20%、弱方损 50%
否则          → 势均，两方各损 35%
```

大运的天干占比自 0.70 线性降到 0.30，地支反向递增。
同一步运里，某个冲的强弱比会随之穿过 1.20 或 2.50 的门槛 ——
**冲的结局会在运程中途改变**。这不是数值噪声，是真实的现象，
而且正是曲线要画出来的东西之一。若把结构冻结在换运那一刻，这一整类变化就消失了。

**所以架构是这样的**：

```
基础盘（算一次，冻结）
  W1_natal = L1(四柱)                    ← 四柱的初始配重
  F_base   = L2(四柱)                    ← 结构因子
  W_base   = L3(W1_natal ⊙ F_base)       ← 冻结。一切 delta 的分母

即时盘 @ t（每个采样点）
  W1_all = W1_natal ∪ L1(大运@t, 流年@t)  ← 四柱部分复用，不重新配重
  F_t    = L2(全部地支)                   ← 全局重检测（三合、冲的裁决）
  W_t    = L3(W1_all ⊙ F_t)
  Δ(t)   = W_t 相对 W_base 的偏离          ← 报告与曲线呈现的量
```

**「不重算」落在两处**：四柱的 L1 配重复用不重算；`W_base` 算一次即冻结，
是所有 delta 的固定分母。**「重算」落在两处**：结构必须全局重检测，
生克必须全局重传导 —— 否则新来的干支就没有作用于命的通道，「运」也就不成其为运。

### 1.1 神煞仍不进入力量模型

你的原话：「神煞更多是给盘面变化一个解释」。方向单向：

```
力量 ──→ 神煞的解读强度（坐旺/坐衰/逢冲/落空/被引动）
神煞 ─╳→ 力量
```

需求 ③ 要「以大运流年神煞为理由」解释异常 —— 这正是单向的用法：
节点由权重曲线检出，检出**之后**再去找那个时点的神煞作为理由。

### 1.2 形体与脏腑：说传统对照，不说这个人

需求 ② 要「长相（五行指事）」与「人体易感的脏腑」，需求 ③ 要「五行指事对应的身体易感部位」。

这两项**可以做**，但必须落在一条明确的线上：

> **陈述「传统对照 + 本盘事实」，不作「关于这个人的判断」。**

具体见 §2.7。可以说「本盘水最弱，占 4.8%；传统上水对应肾与膀胱」——
这是两个可验证的陈述并列。不可以说「肾弱」「易患结石」「注意泌尿系统」——
那是在替读者做推论，而这个系统没有资格做这个推论。

配套的机械约束（§5.3）：**病名一律不得出现在任何报告输出中**，
无条件禁止，不看上下文。器官名可以出现，但只在带「传统上」框定的对照句里。
这条线是可执行的，不靠模板作者自觉。

### 1.3 统计节点是排序工具，不是概率陈述

命盘的时间序列是**确定性的**：大运十年一换、流年六十年一轮、
大运份额线性推移，全部由出生时刻决定。它不是从某个分布抽出的随机样本。

对它算 μ 与 σ，得到的是**这条序列自身的经验散布**。后果：
`|z| ≥ 2` 的采样点必然约占 5%，与这张盘是什么盘无关。

| | |
| -- | -- |
| ✅ 成立 | 「这是本命六十年中，该指标最偏离常态的三段时期」——排序 |
| ❌ 不成立 | 「这一年发生巨变的概率是 5%」——概率 |

报告措辞必须落在前者，由禁用词表拦截（§5.3）。
把百分位包装成统计推断，恰恰会让本来有用的排序失去可信度。

## 2. 基础盘与人格层（需求 ①②）

### 2.0 BaseChart 成为一等对象

现状：`evaluate({ chart })` 在多处被反复调用 —— `yearView` 每年一次、
`monthView` 每月一次、`buildReport` 又一次。它们算的是同一张基础盘，
彼此之间没有「同一个对象」的保证，只有「同一个函数应该给同样结果」的期待。

改为：

```ts
interface BaseChart {
  readonly chart: NatalChart;
  readonly params: Params;
  readonly paramsHash: string;

  /** 四柱的 L1 初始配重。即时盘复用这一份，不重新配重。 */
  readonly l1: readonly Carrier[];
  /** 基础盘的结构事件。 */
  readonly events: readonly StructureEvent[];
  /** **冻结的基础盘权重。一切 delta 的分母。** */
  readonly weights: readonly Carrier[];
  readonly propagation: PropagationResult;
  readonly conclusions: Conclusions;
  readonly shensha: readonly ShenshaHit[];
  readonly persona: Persona;
}

function buildBaseChart(chart: NatalChart, params: Params): BaseChart;
function evaluateAt(base: BaseChart, at: Instant): InstantChart;
```

`evaluateAt` 收 `BaseChart` 而不是 `NatalChart` —— 于是「基准算过一次」
成为**类型层面的事实**，而不是调用方需要记得的纪律。
`InstantChart` 一律携带指回 `base` 的引用与 delta。

**顺带解决的问题**：现在画一条 60 年曲线要重复算 60 次基础盘。
改完之后基础盘算一次，即时盘算 N 次。

| 职责 | 说明 |
| -- | -- |
| **干支五行的呈现** | 二者的干支与五行**单独列出**，不并入加权总量。报告中标为「辅助」 |
| **神煞落点** | 已实现（`mingGong` / `taiyuan` 各有专属宫位，不冒充他柱） |
| **扰动序列** | 命宫支与流年/大运/流月支的冲合刑害，形成一条**扰动曲线**（§3.2） |

第三项是需求 ③ 里「命宫等数值变化」的落法：命宫没有权重，但它有**被引动的程度**。

四十个数值参数不必重新校准，全部测试基线保留。人格层是纯增量。

### 2.2 内 / 外：透干为显，藏支为隐

需求 ② 要「性格偏好」与「外在」。传统里现成的划分是「透干为显，藏支为隐」，
而这个划分**已经在数据里**（载体的 `origin: "revealed" | "hidden"`）。

```
内在分布  I_g = Σ { c.weight : c 为藏干载体, 十神(c) = g }
外在分布  E_g = Σ { c.weight : c 为天干载体, 十神(c) = g }
```

日主自身单列，不计入任一侧（沿用 L4 既有做法）。各自归一化后取三个派生量：

```
显隐比    R = ΣE / (ΣI + ΣE)              外显程度 ∈ [0,1]
内外张力  T = ½ · Σ_k |Î_k − Ê_k|          **按五组算**，k ∈ {比劫,印星,食伤,财星,官杀}
分歧组    按 |Î_k − Ê_k| 降序取前三
```

> **T 必须按五组算，不能按十档。**（实测后修正的一处。）
>
> 外在只有三个天干，与八九个藏干的分布本就难重叠 —— 十档下总变差距离
> 中位数 0.737、5.1% 恰为 1.000。那量的是「外在档位少」，不是「表里不一」。
>
> 按比劫/印星/食伤/财星/官杀五组聚合后：中位数 0.562、顶格率 1.1%，散布可用。
> 五组也是更恰当的粒度 —— 正印与偏印之别，对「表里是否一致」这个问题太细。
> 十档下的值仍然产出（`innerOuterTensionByGod`），但只作明细，不作头条。
>
> **R 的结构区间本就窄**：实测八成的盘落在 0.255–0.361 之间
> （天干占每柱 40%、地支 60%，再经 L3 重分配）。
> 所以 R 只在这个区间内部比较才有意义，报告须给出band 上下文，不宜孤立解读。

**T 不带褒贬。**T 高只表示内在构成与外在构成差异大 ——
传统上既可解为含蓄内敛，也可解为言行不一，取决于分歧落在哪几个十神上。
所以报告必须列出**分歧十神**，而不是只报一个 T 值。

### 2.4 十神 → 特质对照表（四栏）

```ts
interface GodTrait {
  readonly god: TenGod;
  readonly inner: readonly string[];      // 藏而不透
  readonly outer: readonly string[];      // 透干显用
  readonly excess: readonly string[];     // 过旺
  readonly deficient: readonly string[];  // 过弱或缺
}
```

**四栏缺一不可**：同一个十神旺弱表述相反 —— 食神适中为温和从容、太过为疏懒无争；
七杀有制为果决开创、无制为暴戾多惊。只给一栏，强弱两端会说同样的话。

```
过旺  分布占比 > persona.excessShare       0.35
真缺  分布占比 **恰为 0**                  无门槛，无歧义
过弱  0 < 占比 < persona.deficientShare    0.05
```

> **「真缺」与「过弱」必须分开报。**（实测后修正的第二处。）
>
> 原稿只有一档「过弱或缺」，实测每盘平均标出 **4.07 个** ——
> 十档里标四档，等于没标。
>
> 拆开之后：真缺（占比恰为零）每盘均值 2.56 个，且各档分布均匀
> （0 个 2%、1 个 15%、2 个 34%、3 个 29%、4 个 15%），是个有分辨力的量，
> 也正是传统上「四柱缺某神」的准确所指。过弱则降为明细。
>
> 参数校验强制 `excessShare > deficientShare`，
> 否则同一个十神会被同时判为过旺与过弱。

**用词约束**：一律取传统命理的常用表述（自立、竞争、表达、锋芒、务实、灵活、
自律、果决、内省、孤高……），**不用心理学量表词汇**（外向、宜人性、神经质、大五）。
混用会制造虚假的科学感 —— 读者会以为这些词背后有心理测量学的效度，而它们没有。

**底本**：十神性格对应在典籍中分布很散，没有一张现成的表可转录。
我会写出一张站得住的表，标为 `personaSource: 'conventional'`（通行表述），

#### 2.7.2 三个可算的轴

不直接输出「阴虚」「阳虚」这类中医证型，而是给三个从盘面**可算**的轴，
每个轴都能回溯到具体的权重数字。

**轴一 · 虚实**（量的有余与不足）

```
占比      P(e) = W_e / ΣW
相对偏离  d(e) = (P(e) − 0.20) / 0.20              0.20 = 五行均分
受克份额  S(e) = attack(e) / Σattack
受克偏离  a(e) = (S(e) − 0.20) / 0.20              判据用它

d ≥ +excessBand     且 a ≤ band  →  实
d ≥ +excessBand     且 a >  band  →  实而受制
|d| < band          且 a ≤ band  →  平
|d| < band          且 a >  band  →  平而受制     ← 初稿漏了这一档
d ≤ −deficientBand  且 a ≤ band  →  虚
d ≤ −deficientBand  且 a >  band  →  虚而被伐
```

> **两处实测后的修正。**
>
> **其一，判据不能用「受克 / 自身权重」。**初稿写作 `A = attack(e) / W_e`。
> 低权重必然高比值 —— 虚与被伐由构造耦合，「虚而被伐」只是在复述「虚」。
> 实测按它判时该档占 **32%**，成了最常见的一档，与「值得单独措辞」正好相反。
> 改判**受克份额相对均分的偏离**，与虚实的判据同一形式，且与自身权重解耦。
>
> **其二，「平」那一档也必须看受克。**初稿只列五档，「平」不看 a。
> 于是一个占比适中、却承担了全盘 **2.6 倍**份额克流量的五行，
> 会被报成一个干净的「平」—— 那恰恰是这张盘最值得说的一件事，却被埋掉了。
> 补第六档「平而受制」。
>
> 修正后实测（528 盘 × 5 格）：
> 虚 31% · 平 31% · 实 19% · 实而受制 10% · 虚而被伐 9%，散布可用。

「虚而被伐」与「平而受制」是需要单独措辞的两档：
前者量已不足又持续受克，后者看似无恙而实为众矢之的。其余四档共用句式。

**轴二 · 阴阳**（干的阴阳构成）

```
阳占比(e) = Σ{ W_c : c.element = e, c.polarity = 阳 } / W_e
```

> **这是天干的形式阴阳，不是中医的阴阳。**
> 甲阳乙阴是干支系统里的奇偶，中医的阴阳是阴液与阳气。二者同名而异指。
> 把前者直接说成「阳虚」「阴虚」，是一次未经声明的概念跳跃。
>
> 所以报告的措辞是「本盘木**以阳干为主**」，不是「本盘木阳虚」。
> 「阴阳虚实」四个字合起来的意思由轴一与轴二**并列**给出，
> 而不是合成一个中医证型名。

**轴三 · 寒热燥湿**（命理自己的轴，与内经的五气可对接）

这条轴命理本来就有 —— 调候用的正是它，只是尚未单列成量。

```
热势 = P(火) + 0.5·P(木)                木生火，助热
寒势 = P(水) + 0.5·P(金)                金生水，助寒
寒热 H = 热势 − 寒势        ∈ [−1, 1]

燥势 = P(火) + P(燥土)                  燥土 = 藏于未、戌的土
湿势 = P(水) + P(湿土)                  湿土 = 藏于辰、丑的土
燥湿 D = 燥势 − 湿势        ∈ [−1, 1]

月令修正：生于亥子丑，H −= seasonAdjust；生于巳午未，H += seasonAdjust
```

燥土 / 湿土的划分是命理的通行做法（未戌为燥、辰丑为湿），
本项目已有每个藏干载体的 `hostBranch`，直接可分，不需新数据。

**这条轴是新增的可用产出**：它同时能反哺 §调候 —— 现行调候只看
「冬月火占比 < 8%」这类单点判据，有了连续的 H 与 D 之后可以细化。
但**本次不动调候**，避免一次改两处。

模板定死，不允许自由发挥：

#### 2.7.4 「注意可能的问题」怎么写才不越界

你要的是「描述易感、注意可能的问题」，但「不需要给出明确的病」。
这两句合起来正好划出一条可执行的线，我的落法是：

| 写法 | 判定 | 理由 |
| -- | -- | -- |
| 「你会得肝病」 | ❌ | 预言疾病 |
| 「注意心脏病」 | ❌ | 点名病症并指向读者 |
| 「肝系易感」 | ❌ | 仍是对**这个人身体**下的断语 |
| 「传统养生之说据此提示相应系统宜加留意」 | ✅ | 把「留意」归于传统之说，不归于本系统；不点名病症；带免责导向 |

第四行做到了你要的**功能**（读者知道该留意哪一系），
而没有做出这个系统没资格做的**断言**（这个人的身体如何）。

差别不是修辞技巧。前三行如果出现在报告里，读者会合理地认为
「这套算法诊断出我肝有问题」—— 而它没有，它只是数了一下木的权重。

#### 2.7.5 四条硬约束

| # | 约束 | 落实 |
| -- | -- | -- |
| 1 | **病名一律不得出现**（癌、肿瘤、结石、中风、梗、炎、糖尿病、高血压…），无条件，不看上下文 | 禁用规则 `zh.medical.diseaseName` |
| 2 | **易感式断语禁止**（易患、易感、恐有、多有…之疾） | 禁用规则 `zh.medical.susceptibility` |
| 3 | **脏腑段必须同时带传统框定语与免责导向**，缺一即拦 | `requireContext`，双条件 |
| 4 | **`subject: "other"` 时整节不生成** | 结构性略去 —— 形体与脏腑都是对一个人身体的描述 |

因为脏腑是所有输出里最容易被当成医嘱的一节。

### 2.8 神煞给出「强在哪里、为什么强」

需求 ② 的最后一句：「根据神煞给出命主性格、指事的解释（强在哪里？为什么强？）」。

神煞不产生结论，它**解释已有的结论**。算法：

```
对人格层的每条结论 c（主导十神、过旺五行、某宫得力…）：
  1. 找出支撑 c 的载体集合 S（如「正官主导」→ 全部正官载体）
  2. 取落在 S 所在宫位上的神煞
  3. 按以下顺序排列作为解释素材：
       tone = strengthened / activated 者优先
       narrativeTags 与 c 的特质词有交集者优先
       其余按 hostWeight 降序
  4. 叙述形如：「{结论}。该{宫位}另见{神煞}，传统上与{标签}一类语汇相联系。」
```

「为什么强」的答案来自**力量层**（通根、司令、透干、得生），
神煞只补「传统上此处还被赋予什么含义」。二者在叙述中分句，不混。

### 3.3 采样：月度

你写的是「按照大运流年的时间（**年度/月度**）命盘」。采月度，理由是曲线本来就是连续的：

- **流年**是阶跃：立春换柱
- **大运**是连续斜坡：天干占比自 0.70 线性降到 0.30，
  每年约有 5.2 个单位的力量从天干移向地支
- **结构的结局也在运内变化**：冲的强弱比会穿过 1.20 / 2.50 门槛（§1.0 反例二）

第三条已实测证实，不是推想：**528 步运里 191 次**出现同一组参与者的事件结局翻转。
形态举例 ——

```
运壬申 · 2013 · 冲(大运↔月柱)    冲而拔根  ⇄  相冲          强弱比穿过 2.50
运丙子 · 2008 · 冲(大运↔月柱)    合解冲    ⇄  相冲          冲合裁决整个反转
运丙子 · 2007 · 六合(月柱↔年柱)  争合      ⇄  合被冲破
```

第二行最要紧：一个原本被合解掉的冲，在运程中途生效了。年度采样看不到这件事。

所以改为**每月一个采样点**：

```
60 年 × 12 = 720 点
120 年 × 12 = 1440 点
```

**流月仍不参与权重** —— 曲线之所以在月度上有变化，是因为大运份额在连续推移，
不是因为流月加了分。这一点必须在报告里写明，否则读者会误以为流月在加权。

**实测**：60 年 × 12 = 720 点，`buildSeries` 约 **590 ms**（基础盘只算一次；
立春每年解一次牛顿求根，不是每个采样点解一次）。Web 端首次进入曲线页算一次并缓存。

**月内变化确实存在，且两个来源可分**：实测非换运年的月内极差最大 12.1（大运斜坡），
换运年最大 113.1（换柱）。前者正是年度采样会抹掉的那一部分。

> **不能按（大运, 流年）缓存结构检测**：冲的裁决依赖相对权重，
> 而权重逐月推移。缓存会把「运内结局翻转」这个真实现象抹掉。

## 4. 统计节点（需求 ③）

### 4.1 两个量

你的原话：「高于和低于的偏离都会造成变化，表示的是**变化率和变化量**」。

```
变化量  z(t)  = (q(t) − μ) / σ                       水平偏离
变化率  ż(t)  = (q(t) − q(t−P) − μ_Δ) / σ_Δ          同比差分的偏离
```

μ、σ 取该指标在**基准窗**内的中心与散布；μ_Δ、σ_Δ 为差分序列的均值与标准差。

**⚠️ 差分的步长 P 是一整年（月度序列取 12），不是一个月。**

规格初稿写的是一阶差分。实现后实测发现：几乎**每一个**节点都起于寅月。
原因是月度序列被一个周期为 12 的确定性阶跃主导 —— 每年立春换流年柱，
曲线必跳一次。对月度一阶差分做 z 分数，量到的是「立春跳变比月内漂移大」，
而这**永远成立**，与这张盘是什么盘无关。
取同比差分则两端处于同一年内相位，立春的跳变相消，剩下的才是真的趋势变化。
中尺度的序列本就是每步一值，步长取 1。

**节点判据**：`max(|z|, |ż|) ≥ θ`。三种形态分别标注：

| 形态 | 判据 | 含义 |
| -- | -- | -- |
| **持续极端** | 高 \|z\|、低 \|ż\| | 长期处于偏离态 |
| **急速穿越** | 低 \|z\|、高 \|ż\| | 量不极端但变得很快 —— 换运前后的典型形态 |
| **突入极端** | 两者皆高 | 最强 |

只报一个合成分数，会把「一直如此」与「突然变成这样」混为一谈。

**θ 是参数，不是常数。**默认 2（`nodes.threshold`），也可就地覆盖
`findNodes(S, scale, { threshold: 1.5 })`。它没有任何理论地位 ——
序列是确定性的，改 θ 改的是**入选条数**，不是「显著性水平」。
实测大尺度：θ=1.5 → 463 段，θ=2 → 221 段，θ=3 → 28 段。

### 4.2 三个尺度

| 节点 | 序列 | 基准窗 | 回答 |
| -- | -- | -- | -- |
| **小** | 月值 | 所在大运的 120 个月 | 这个月在**本运中**有多异常 |
| **中** | 大运步均值（每步一值） | 起运后 60 年的 6 步 | 这一步运在**一生中**有多异常 |
| **大** | 月值 | 起运后 60 年的 720 个月 | 这个时点在**一生中**有多异常 |

**⚠️ 采样不足的那一「步」不参与中尺度统计。**统计窗起点通常落在起运之前，
`luckIndex` 为 null 的那一段实测只有 7 个月，它的均值却与整整十年的均值
并列参与统计。实测后果：对一条**纯线性上升**的序列，这个残段自己就能撑出
一个 −2.23σ 的假中节点 —— 一条直线报出了「节点」。
门槛取最长一步的一半，随采样密度自适应，不另设参数。

### 4.3 ⚠️ 中节点必须用稳健估计

样本量只有 6。样本标准差极不稳 —— 任何一步稍偏都会被放大成 2σ，
中节点近乎恒有产出，也就等于没有产出。

```
M   = median(x)
MAD = median(|x − M|)
稳健 z = 0.6745 × (x − M) / MAD
```

0.6745 = Φ⁻¹(0.75)，使 MAD 在正态下等于 σ。
若 `MAD = 0`（六步全同），该指标**不产出中节点**，不做任何回退 ——
没有散布就没有偏离可言。

#### 4.3.1 ⚠️ 但中节点的 σ 比值**不得作为陈述出现**

这一条是实现后加的，起因是量到了下面这组数。
`正印` 的六步大运步均值：

```
4.64   5.39   46.04   4.74   4.97   18.95
M = 5.18   MAD-σ = 0.716   →   z = −0.7  0.3  57.1  −0.6  −0.3  19.2
```

`57.1σ`。而同一张盘的大尺度节点，|z| 最高只有 5.9。
两个数一旦并列，读者会当成同一把尺子上的读数 —— 它们完全不是：
n=6 时 σ 由两个次序统计量估出，四五步取值相近就能把比值推到几十。

这个数**说的事情是对的**，只是不该用这个形式说。它想说的是
「六步里有四步都在 5 上下，这一步是 46」，那就直接这么说：

```
中节点摘要： {label}在 {span}这一步，在这 {steps} 步大运中明显偏离
             （该步 {peakValue}，各步中位 {mean}，{shape}·{direction}）。
中节点展开： …另有 {flatSteps} 步都落在中位附近。
             此处不引「几个标准差」——（说明 n=6 的估计为何不可比）
```

比值仍保留在证据表里，**用来排序**：排序只需单调，不需量纲可比。
同理，中尺度也不单独陈述 ż —— 它在 5 个差分上估出，一样不稳。

### 4.4 节点 = θσ 穿越区间，不是孤立时点

你写的是「得到和 2sigma 的**时间交点**」—— 交点，不是峰值。这个说法更准确，采纳。

```
穿越区间 = max(|z|,|ż|) ≥ θ 的极大连续区间（同号者相隔 ≤ bridge 个采样点则并作一段）
  t_in    进入点
  t_peak  区间内 max(|z|,|ż|) 的极值点
  t_out   离开点
  持续     t_out − t_in
  面积     Σ(max(|z|,|ż|) − θ)        ← 「变化量」的积分形态
```

**桥距按月折算。**`bridgeGapMonths` 的单位是月，而区间合并的单位是**采样点**，
两者只在月度尺度上碰巧相等。中尺度一个采样点是一整步大运（120 月），
若把 2 直接当作 2 个点，就成了「隔二十年也算同一段」。

#### 4.4.1 ⚠️ 月序何时携带信息，何时是伪精度

规格初稿只说「插值只到月」。实现后实测发现，对**权重类序列**连「到月」都是伪精度：

| 序列类 | 节点起于寅月的比例 |
| -- | -- |
| 扰动（吃流月） | 27 % |
| 内外、综合 | 43 %–50 % |
| 十神、五行、宫位、日主、应期域 | **81 %–100 %** |

原因是模型的直陈，不是噪声：**流月只入符号层**（`fleetingMonthInWeights: false`，
硬约束），于是立春年内唯一在动的权重来源是大运斜坡，而它缓慢单调；
真正的跳变全部发生在立春换柱那一刻。同比差分消掉了立春在**变化率**上的痕迹，
但**水平**上的年阶跃是真的。

所以 `Series` 带一个 `monthResolving`、节点带一个 `monthResolved`：

```
monthResolving = true   仅扰动序列 —— 报「2046 年酉月至 2057 年丑月」
monthResolving = false  其余全部   —— 报「2046 年」或「2003–2004 年」
```

对权重类写「2046 年寅月起」，说的其实是「2046 这个立春年」。
把这件事标出来，而不是藏起来。

#### 4.4.2 为什么没有「覆盖率上限」这条护栏

初版参数里有一条 `maxCoverage`：一段穿越若占满大半个基准窗，
就不是偏离，是基准取错了。**它已删除 —— 因为它永远不会触发**，
而永不触发的护栏只会让人以为有一层其实不存在的保护。

- 中尺度可证：MAD 是偏差的中位数，若过半的点满足 `d ≥ 2.965·MAD`，
  则 `MAD ≥ 2.965·MAD`，只能 `MAD = 0` —— 而那时 σ=0，序列本就被排除。
  故越阈点不超过一半；桥距在中尺度又折算为 0，覆盖率恒 ≤ 0.5。
- 小、大两尺度用样本标准差，`Σz² = n` 强制 `|z| ≥ 2` 的点不超过 n/4，
  变化率一路同理，合并也不到一半；且**桥接不跨号**，
  而尖峰序列的变化率必然一升一降成对出现，链条总被异号段打断。

该性质改由 `nodes.spec.ts` 当作不变量断言（三个尺度 × 三档门槛），
不再当作运行期过滤。

### 4.5 方向不定吉凶，但要标出

`z > 0` 与 `z < 0` **都是节点**。是机会还是压力，取决于指标与用忌的关系：

```
指标属用神向（用神/喜神的十神或五行）：偏离为正 → 偏机会    为负 → 偏压力
指标属忌神向（忌神/仇神）：            偏离为正 → 偏压力    为负 → 偏机会
宫位权重 / 宫位扰动 / 显隐比：         不判方向，只报「该宫变动」
应期域·张力：                          **恒不判方向**
应期域·净值：                          判方向（net = 顺 − 逆，符号即方向）
```

**域张力恒不判方向**：张力本身就是「顺逆并存」的度量，
给它定吉凶等于把已经拆开的东西又合回去 —— 那正是 tension 存在的理由。
**但净值不同**：`net = supporting − opposing`，符号就是方向。
初版两条都写了 neutral，后果是「婚姻感情·净值 −5.94σ」这样的节点一律报
「只报变动」，趋避一节（需求 ⑤）因而几乎空着 —— 而那恰恰是最该有内容的地方。

#### 4.5.1 ⚠️ 定吉凶取**驱动这个峰的那一个分量**

峰按 `max(|z|, |ż|)` 取。若驱动它的是 ż（急速穿越），
该点的水平往往正处在常态附近 —— 用它的符号判吉凶等于掷硬币。
此时改用变化率的方向：升即为正。持续极端与突入极端两种形态下，两者相同。

节点因此带两个符号：`sign`（水平偏离的方向，供陈述）与
`driveSign`（驱动峰的方向，供定吉凶）。

### 4.6 神煞作为「异常的理由」

节点检出**之后**，在 `t_in` 前后一个月的窗口内取即时盘的符号层，取三类作为理由：

```
1. 神煞的 tone 为 activated（被引动）
2. 该窗口内牵动大运或流年的结构事件（三合成局、冲、刑、开库…）
   —— 纯本命的结构在基础盘里就有，不是这一刻的变化
3. 该窗口内触发的应期规则
```

按「与 t_in 的时间距离」升序排列 —— **最靠近进入点的，最像是引发它的**，至多六条。

> **规格初稿另列了两条，实现时未采用**：「神煞落在本节点涉及的宫位上」与
> 「神煞的域标签与本节点的域重叠」。二者都是**静态**匹配 ——
> 本命神煞落在哪个宫、带哪些域标签，是基础盘就定下的，
> 六十年里每一个时点都成立。把它们列为「这一刻变化的理由」，
> 等于给每条节点都配上同一批理由，而恒真的理由不解释任何事。
> 保留的三条都要求**该时刻发生了什么**。

中尺度的理由另走一路：十年之变，因在运不在年，故理由就是那几步大运本身
（「第 4 步大运 乙酉，天干之木为闲神」）。

叙述形如：

> 2031 年 3 月起，官杀曲线进入偏离区（z = 2.3，持续至 2033 年 8 月，
> 2032 年 5 月最甚 z = 3.1）。同期流年支冲日支，配偶宫的驿马被引动，
> 大运支与本命月支三合成局。传统上这三项与变动、迁移一类语汇相联系。

注意末句的形状：**结构事实在前，传统语汇在后，中间不加因果连接词。**

**理由在截断之后才找。**每条理由要跑一次 `evaluateAt` 加一遍应期，约 4 ms。
对全部越阈段都算而后只留前十二条，就是把九成五的工作丢掉 ——
实测浏览器主线程因此卡住近一秒。先排序截断，再给留下来的那几条找理由。

### 4.7 五行指事在节点上的复用

需求 ③ 末句：「五行指事对应的身体易感部位一样可以提出」。

复用 §2.7 的配属表与三条轴，只是取值来自**节点时段**而非基础盘：

```
当某五行序列进入偏离区（偏高或偏低皆算）：
  「{t_in}–{t_out} 期间，{e} 偏离常态（z = {z}，{t_peak} 最甚）。
   该时段 {e} 为{虚实档}，以{阳|阴}干为主，寒热偏{H}、燥湿偏{D}。
   《内经》五行配属中，{e}应{脏}与{腑}，在窍为{窍}，在体为{体}。
   传统养生之说据此提示相应系统宜加留意。
   以上为传统对照与盘面数值的并列陈述，不构成任何关于身体状况的判断，
   亦不指向任何具体病症；健康相关的决定请咨询持证专业人士。」
```

**关键在「偏高或偏低皆算」**：这正是你说的「高于和低于的偏离都会造成变化」。
在内经的框架里二者也对应不同的一侧 —— 太过与不及，都是失衡。

§2.7.5 的四条硬约束**同样适用**，无例外。
节点段的措辞与基础盘段共用同一批模板，只换槽位来源 ——
两处若各写一套，迟早只有一处被守卫扫到。

## 4a. 两层结论与趋吉避凶（需求 ④⑤）

### 4a.1 一条不变量：摘要里的每个数字，都必须在展开层的证据里找得到

需求 ④ 是「默认输出简单结论，点击查看详细解释」。分两层写的报告有一种
**特有的失真方式**：摘要写「财运向好」，展开写「财星被劫、比劫夺财」，
两层各自都不算错，合起来却把一个有保留的判断变成了无保留的断言 ——
而**读者通常只看一层**。

`auditFinding` 把摘要里出现的每一个数字抠出来，逐个要求它等于某条
`Evidence` 的规范化取值，**构建期即执行**，对不上直接抛。

```
Evidence { label, value, unit, ref }
  unit   sigma | value | share | count | year | months
  ref    node:tenGod.正财 | shensha:羊刃 | luck:4 | series:window

formatEvidence 是全系统唯一把 Evidence 变成串的地方 ——
摘要写 3.5、展开写 3.54，机械比对便认不出它们是同一个数。
```

它拦不住形容词层面的失真（那需要语义判断，此处不假装能做到），
但拦得住数字层面的，而分层报告出问题十有八九正是这一种。

两条实现上的教训：

- **取值精度随量级走**（`unit: "value"`）。一律 `toFixed(1)` 会把
  同党占比的 `0.473` 与 `0.358` 压成 `0.5` 与 `0.4` ——
  读起来像两个几乎相同的数在争谁更偏离，而它们相差整整一个 MAD。
- **区间连字符不是负号**。审计第一次跑就报了警，抓的是它自己：
  `2003–2004 年` 里的破折号被半角化成减号，`–2004` 于是被读成一个负数。
  只把真正的减号（U+2212）半角化，破折号留着。

**摘要也走模板。**§0 的硬约束是「报告层不做新判断」，而摘要是最容易破这条
规矩的地方 —— 它短、要好读、又最显眼。故摘要与展开走同一套模板机制，
同样受置信度降级与措辞守卫管辖。

**吉凶取向单独存字段。**摘要措辞随尺度而变（中尺度不引 σ 比值），
拿字符串去判方向早晚会读错 —— 初版的测试正是这么写的。

### 4a.2 趋吉避凶

需求 ⑤ 是「可能遇到的问题、神煞诱因、注意的规避方案」。三者一一对应：

```
problem   哪一域、什么形态 —— 只写结构，不写具体事件
trigger   该节点自己的神煞理由（§4.6 的第一类）
line      传统趋避之说 —— 描述姿态，不指派动作
```

只对**压力向**的节点产出。「趋吉」那一半在本系统里只能说成「此段顺遂」，
那是同一句话换个说法，不另立一条；不判方向的节点同样不产出 ——
张力本就是顺逆并存的度量，给它派一个规避方案等于把已经拆开的东西又合回去。

三种形态各配一句姿态性的话：

| 形态 | 传统趋避之说主张 |
| -- | -- |
| 持续极端（一段状态） | 以守代攻、缓图为上 |
| 急速穿越（一次转折） | 凡事多留一分回旋，不轻许诺 |
| 突入极端（两者兼有） | 先安内而后图外，不宜多头并进 |

#### 4a.2.1 ⚠️ 每条趋避自带传统框定与免责导向

**因为它是全份报告里最容易被单独复制走的一块。**一句孤零零的「宜守不宜攻」
就是建议，无论它原本挂在多少免责声明底下。故三条各自是**完整成句**的模板，
而不是「框架 + 可插拔的短语」。

写成片段的那一版被措辞守卫当场拦下了，守卫是对的：那个串一旦存在于模板库里，
就是一句可以被原样摘走的行动指令，无论调用方本来打算把它插进多完整的框定里。

判定域是**段**，与脏腑段同一个理由、同一种做法（见 §5.3）。

### 4a.3 一条趋避都没有时，必须说清那不等于「一生平顺」

```
「本命六十年中没有张力显著偏高的时段可供列举。这说的是这条序列自身的散布较平，
  不是「一生平顺」—— 同一套判据在任何一张盘上都只挑出最偏的那几段。」
```

空着会被读成「一生平顺」，而那是这套判据根本不能支持的结论。

三种形态各自是一条完整成句、自带框定与免责的模板。

**一条实现上的注意**：`zh.body.framing` 的 `context` 用了两个前瞻断言，
必须在**整段**（而非整句）上求值 —— 框定语在段首、免责语在段尾是正常的写法。
故这条规则的判定域是「段」，需要 `scanText` 支持第三种判定域。
现行守卫只有「±4 字窗」与「整句」两档，需新增「整段」。

### 6.1 P11 完成记录

**「恰好算一次」的可断言形式是引用相等**，不是计数。
`EvaluatedChart` 携带 `base: BaseChart`，于是断言写成：

```ts
const seen = new Set(report.years.cards.map((c) => c.view.evaluated.base));
expect(seen.size).toBe(1);
```

不需要给 `core` 加任何计数器（那会引入全局可变状态，与「纯函数」相悖）。

实测：`buildReport` 九十年曲线 **148 ms → 84 ms**。
省下的正是 `yearView` 每年重解一遍本命盘 —— 一条 120 年曲线就是 120 遍。
（`luckTimeline` 本来就只解一次本命，故那里没有收益；
我最初写的注释说它「十二步就是三十七遍」是错的，已改正。）

**顺带修出的两处问题**：

- **透干把岁运算了进去。**`revealedStems` 原先建在**全部**天干上，
  于是流年天干会把本命藏干标成「透干」。透干是恒定的结构属性，
  岁运带来同字是当时的引动，明年就没了 —— 两个概念被混成一个。
  拆为 `REVEALED` / `EVOKED`，二者可并存。
  此改动不影响任何权重（`revealedResonance` 刻意置 1.00），只影响展示。
  但它同时是**基础盘能够冻结复用的前提**：不拆，四柱的 L1 就与时点有关。

- **卡片窗口越出曲线跨度时，§6.2 静默变空。**卡片原先挂在曲线循环里，
  `curveYears: 20` 而 `now` 在四十年后，报告里那一节就没了，也不说为什么。
  改为两个环各自遍历、重叠年份共用缓存。

### 6.2 P12 完成记录

**置信度与并列门槛由构造对齐。**主导十神的置信度取

```
confidence = 0.45 + 0.15 × gap / dominantMargin
```

`gap = dominantMargin` 时恰得 **0.60**，即模板的 `confidenceFloor`。
于是「判为并列」与「改用留有余地的措辞」永远同进同出，
**且这一点与 `dominantMargin` 取多少无关** —— 测试对 0.02/0.05/0.12/0.30 四个取值都验过。

实测外在主导判为并列的占比 26.3%。这个比例偏高，但它是结构性的：
外在只有三个天干，两个不同十神权重接近的情形本就常见。
并列时报告自动改用留有余地的措辞，正是为这类情形准备的。

**两处实测后修正**：内外张力改按五组算（§2.2 附注）、真缺与过弱分开报（§2.4 附注）。
二者都是先量分布、再定形，而不是照着初稿实现完就算数。

**顺带修出的两处**：

- **自身宫凭空多一个比肩。**宫位的十神构成把日主自己也算了进去。
  「日主是参照点，不是自己的比肩」是 L4 十神向量的既有规矩，
  我在宫位统计里破了它。已排除，并标 `isDayMaster`。
- **JSX 文本里的 Markdown 无效。**三处 `**结构**` 会原样渲染成星号，
  P9b 就带进来了 —— 当时只截了页面顶部，没看到。
  新增 `scripts/check-web-text.mjs` 兜底，并验过它逮得住植入的违规。

### 6.3 P13 完成记录

**守卫新增「段」判定域。**段界取空行与 Markdown 块首（列表项、编号、标题、引用、表格行），
于是一份 Markdown 里每条列表项各自成段 —— **第五条里的免责声明不会替第二条把关**，
而读者只会读到第二条。单行文本整条即一段，这正是报告层逐条扫描时要的粒度：
**能被单独复制走的那一块，必须自己站得住。**

`zh.body.framing` 是全表唯一要求两个条件同时成立的规则（框定语 + 免责导向，缺一即拦），
配套 `zh.medical.diseaseName`（病名无条件禁止）与扩充后的 `zh.medical.contract`
（易感式断语）。三条各有真实反例，且验过「炎上」「五气之中，风为木之气」不被误伤。

**三条轴的两处修正**见 §2.7.2 的附注 —— 都是先量分布、再定形。

**顺带修出的一处**：模板文本里写了 Markdown 粗体。同一份模板要喂给
Markdown 导出、Web 的纯文本渲染、CLI 与 Skill 的 JSON —— 只有 Markdown 认得
`**粗体**`，其余三处会原样显示成星号。强调不是承重的东西，已全部去掉，
并加断言：模板文本不得含粗体、代码跨度、链接三类 Markdown 语法。

### 6.4 P14 完成记录

**曲线不进 `Report`。**55 条 × 720 点约四万个数，序列化进每份报告会让 JSON 涨到几百 KB ——
而 Skill 场景下模型是要把整份 JSON 读进上下文的。
曲线是**可视化**，节点才是**结论**：P15 把节点（一个很小的摘要）放进报告，

这是月度采样两条理由中的第二条 —— 第一条（大运斜坡）实测非换运年月内极差最大 12.1。

**序列 55 条**（初稿估作 47），720 点约 590 ms。

**一处推理更正**见 §3.2.2：z 分数对平移不变，故「节点必须跑在偏离上」是错的；
而权重类偏离含大运流年带来的六成新质量，不可读作净增长。
