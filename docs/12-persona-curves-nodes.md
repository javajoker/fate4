## 1. 先厘清四条边界

### 1.0 「不再重新计算基础盘」的准确含义

你写的是：「基础盘是后续计算基准，不再重新计算基础盘。基于基础盘计算新的大运流年时间命盘。」

这句话包含两个可能的读法，**第一个成立，第二个不成立**，必须分开：

| 读法 | 是否成立 | 说明 |
| **基础盘只算一次，冻结为定值，一切时点结果都以它为参照** | ✅ **完全照办** | 见 §2.0 |
| **即时盘不再跑全局的结构与生克，只在基础盘上叠加大运流年** | ❌ **做不到，也不该做** | 见下 |

第二个读法为什么不成立 —— 两个具体的反例：

**其一，三合需要全部地支同时在场才看得见。**
本命有寅、午两支，本身只成半合。流年来一个戌，寅午戌三合火局立成，
化神之火大增、非化神之支大减。这个判定**必须**在「本命四支 + 大运支 + 流年支」
的完整支集上重新检测 —— 只看基础盘的结果，永远看不到这个局。

**其二，冲的裁决依赖相对权重，而权重在运内是连续变化的。**
`structure/apply.ts` 中冲的损耗分三档，按强弱比 `ratio` 判：

```
ratio ≥ 2.50  → 拔根，弱方损 75%
ratio ≥ 1.20  → 强方损 20%、弱方损 50%
否则          → 势均，两方各损 35%
```

大运的天干占比自 0.70 线性降到 0.30，地支反向递增。
同一步运里，某个冲的强弱比会随之穿过 1.20 或 2.50 的门槛 ——
**冲的结局会在运程中途改变**。这不是数值噪声，是真实的现象，
而且正是曲线要画出来的东西之一。若把结构冻结在换运那一刻，这一整类变化就消失了。

**所以架构是这样的**：

```
基础盘（算一次，冻结）
  W1_natal = L1(四柱)                    ← 四柱的初始配重
  F_base   = L2(四柱)                    ← 结构因子
  W_base   = L3(W1_natal ⊙ F_base)       ← 冻结。一切 delta 的分母

即时盘 @ t（每个采样点）
  W1_all = W1_natal ∪ L1(大运@t, 流年@t)  ← 四柱部分复用，不重新配重
  F_t    = L2(全部地支)                   ← 全局重检测（三合、冲的裁决）
  W_t    = L3(W1_all ⊙ F_t)
  Δ(t)   = W_t 相对 W_base 的偏离          ← 报告与曲线呈现的量
```

**「不重算」落在两处**：四柱的 L1 配重复用不重算；`W_base` 算一次即冻结，
是所有 delta 的固定分母。**「重算」落在两处**：结构必须全局重检测，
生克必须全局重传导 —— 否则新来的干支就没有作用于命的通道，「运」也就不成其为运。

### 1.1 神煞仍不进入力量模型

你的原话：「神煞更多是给盘面变化一个解释」。方向单向：

```
力量 ──→ 神煞的解读强度（坐旺/坐衰/逢冲/落空/被引动）
神煞 ─╳→ 力量
```

需求 ③ 要「以大运流年神煞为理由」解释异常 —— 这正是单向的用法：
节点由权重曲线检出，检出**之后**再去找那个时点的神煞作为理由。

### 1.2 形体与脏腑：说传统对照，不说这个人

需求 ② 要「长相（五行指事）」与「人体易感的脏腑」，需求 ③ 要「五行指事对应的身体易感部位」。

这两项**可以做**，但必须落在一条明确的线上：

> **陈述「传统对照 + 本盘事实」，不作「关于这个人的判断」。**

具体见 §2.7。可以说「本盘水最弱，占 4.8%；传统上水对应肾与膀胱」——
这是两个可验证的陈述并列。不可以说「肾弱」「易患结石」「注意泌尿系统」——
那是在替读者做推论，而这个系统没有资格做这个推论。

配套的机械约束（§5.3）：**病名一律不得出现在任何报告输出中**，
无条件禁止，不看上下文。器官名可以出现，但只在带「传统上」框定的对照句里。
这条线是可执行的，不靠模板作者自觉。

### 1.3 统计节点是排序工具，不是概率陈述

命盘的时间序列是**确定性的**：大运十年一换、流年六十年一轮、
大运份额线性推移，全部由出生时刻决定。它不是从某个分布抽出的随机样本。

对它算 μ 与 σ，得到的是**这条序列自身的经验散布**。后果：
`|z| ≥ 2` 的采样点必然约占 5%，与这张盘是什么盘无关。

| | |
| ✅ 成立 | 「这是本命六十年中，该指标最偏离常态的三段时期」——排序 |
| ❌ 不成立 | 「这一年发生巨变的概率是 5%」——概率 |

报告措辞必须落在前者，由禁用词表拦截（§5.3）。
把百分位包装成统计推断，恰恰会让本来有用的排序失去可信度。

## 2. 基础盘与人格层（需求 ①②）

### 2.0 BaseChart 成为一等对象

现状：`evaluate({ chart })` 在多处被反复调用 —— `yearView` 每年一次、
`monthView` 每月一次、`buildReport` 又一次。它们算的是同一张基础盘，
彼此之间没有「同一个对象」的保证，只有「同一个函数应该给同样结果」的期待。

改为：

```ts
interface BaseChart {
  readonly chart: NatalChart;
  readonly params: Params;
  readonly paramsHash: string;

  /** 四柱的 L1 初始配重。即时盘复用这一份，不重新配重。 */
  readonly l1: readonly Carrier[];
  /** 基础盘的结构事件。 */
  readonly events: readonly StructureEvent[];
  /** **冻结的基础盘权重。一切 delta 的分母。** */
  readonly weights: readonly Carrier[];
  readonly propagation: PropagationResult;
  readonly conclusions: Conclusions;
  readonly shensha: readonly ShenshaHit[];
  readonly persona: Persona;
}

function buildBaseChart(chart: NatalChart, params: Params): BaseChart;
function evaluateAt(base: BaseChart, at: Instant): InstantChart;
```

`evaluateAt` 收 `BaseChart` 而不是 `NatalChart` —— 于是「基准算过一次」
成为**类型层面的事实**，而不是调用方需要记得的纪律。
`InstantChart` 一律携带指回 `base` 的引用与 delta。

**顺带解决的问题**：现在画一条 60 年曲线要重复算 60 次基础盘。
改完之后基础盘算一次，即时盘算 N 次。

### 2.1 胎元与命宫：辅助，不入权重

按你的答复：**基础盘只取四柱内容**。胎元与命宫的三项辅助职责：

| 职责 | 说明 |
| **干支五行的呈现** | 二者的干支与五行**单独列出**，不并入加权总量。报告中标为「辅助」 |
| **神煞落点** | 已实现（`mingGong` / `taiyuan` 各有专属宫位，不冒充他柱） |
| **扰动序列** | 命宫支与流年/大运/流月支的冲合刑害，形成一条**扰动曲线**（§3.2） |

第三项是需求 ③ 里「命宫等数值变化」的落法：命宫没有权重，但它有**被引动的程度**。
定义见 §3.2.3。

**这个答复的好处**：现有的旺衰、用神、格局、六亲、参数全部不动，
四十个数值参数不必重新校准，全部测试基线保留。人格层是纯增量。

### 2.2 内 / 外：透干为显，藏支为隐

需求 ② 要「性格偏好」与「外在」。传统里现成的划分是「透干为显，藏支为隐」，
而这个划分**已经在数据里**（载体的 `origin: "revealed" | "hidden"`）。

```
内在分布  I_g = Σ { c.weight : c 为藏干载体, 十神(c) = g }
外在分布  E_g = Σ { c.weight : c 为天干载体, 十神(c) = g }
```

日主自身单列，不计入任一侧（沿用 L4 既有做法）。各自归一化后取三个派生量：

```
显隐比    R = ΣE / (ΣI + ΣE)              外显程度 ∈ [0,1]
内外张力  T = ½ · Σ_g |Î_g − Ê_g|          总变差距离 ∈ [0,1]
分歧十神  按 |Î_g − Ê_g| 降序取前三
```

**T 不带褒贬。**T 高只表示内在构成与外在构成差异大 ——
传统上既可解为含蓄内敛，也可解为言行不一，取决于分歧落在哪几个十神上。
所以报告必须列出**分歧十神**，而不是只报一个 T 值。

### 2.3 月令不额外加权，但司令干单列

月令已在 L1 有 2.0 倍放大与司令加成。人格层不再加权 —— 同一份信息不数两遍。
但**司令干**单独标出，作为「禀气的底色」。这是标注，不是加权。

### 2.4 十神 → 特质对照表（四栏）

```ts
interface GodTrait {
  readonly god: TenGod;
  readonly inner: readonly string[];      // 藏而不透
  readonly outer: readonly string[];      // 透干显用
  readonly excess: readonly string[];     // 过旺
  readonly deficient: readonly string[];  // 过弱或缺
}
```

**四栏缺一不可**：同一个十神旺弱表述相反 —— 食神适中为温和从容、太过为疏懒无争；
七杀有制为果决开创、无制为暴戾多惊。只给一栏，强弱两端会说同样的话。

```
过旺  分布占比 > persona.excessShare      建议 0.35
过弱  < persona.deficientShare            建议 0.05（为 0 即「缺」）
```

**用词约束**：一律取传统命理的常用表述（自立、竞争、表达、锋芒、务实、灵活、
自律、果决、内省、孤高……），**不用心理学量表词汇**（外向、宜人性、神经质、大五）。
混用会制造虚假的科学感 —— 读者会以为这些词背后有心理测量学的效度，而它们没有。

**底本**：十神性格对应在典籍中分布很散，没有一张现成的表可转录。
我会写出一张站得住的表，标为 `personaSource: 'conventional'`（通行表述），
列入待校准清单 —— 与调候表同样的处理。

### 2.5 五行 → 性格偏好

十神之外，五行本身另有一层（需求 ② 明写「性格偏好（五行、十神等）」）。

```
五行分布 P_e = W_e / Σ W        （取自基础盘权重）
偏枯度   K   = 1 − H(P)/ln 5     归一化熵的补，∈[0,1]，越高越偏
最旺 / 最弱 五行，及其与日主的关系（同我 / 我生 / 我克 / 克我 / 生我）
```

五行的性格表述与十神表述**并列呈现，不合并** —— 二者是同一份权重的两种投影，
若合并成一句，读者无从判断某个说法的来源。

### 2.7 五行指事 —— 形体与脏腑

这一节的算法很简单，**难的全在措辞的形状**，所以规格写得比算法长。

#### 2.7.1 两张固定对照表

```
形体  木 修长挺拔    火 尖露明快    土 厚重敦实    金 方正结实    水 圆润灵活
脏腑  木 肝 · 胆     火 心 · 小肠   土 脾 · 胃     金 肺 · 大肠   水 肾 · 膀胱
```

二者都是**传世的固定对照**，不含任何计算，也不因盘而异。

#### 2.7.2 与本盘结合的方式

只做一件事：**指出本盘哪个五行最旺、哪个最弱、哪个受克最重**，
然后把上表对应的那一格念出来。仅此而已，不作推论。

```
形体：取最旺五行（并列时全部列出）
脏腑：取三类 —— 最旺、最弱、受克流量最大者
```

#### 2.7.3 输出的固定形状

模板是**定死的**，不允许自由发挥：

```
形体  「本盘{element}最旺，占 {share}。传统上{element}对应{形体词}一类形貌。
       此为五行与形貌的传统对照，非体检结论。」

脏腑  「本盘{element}{最弱|受克最重}，占 {share}{，受{克者}克 {damage}}。
       传统上{element}对应{脏}与{腑}。
       此处只陈述传统对照与盘面事实，不构成任何关于身体状况的判断；
       健康相关的决定请咨询持证专业人士。」
```

#### 2.7.4 三条硬约束

| # | 约束 | 落实方式 |
| 1 | **病名一律不得出现**（癌、炎、结石、中风、糖尿病、高血压、肿瘤、梗、瘤…） | 无条件禁用规则，不看上下文 |
| 2 | **脏腑句必须带传统框定语与导向专业人士的一句** | `requireContext` 规则 |
| 3 | **`subject: "other"` 时整节不生成** | 结构性略去 —— 形体与脏腑都是对一个人身体的描述 |

第 1 条是无条件的：器官名可以出现在带框定的对照句里，**病名一个都不行**。
这条线清楚、可执行，且不需要判断上下文。

### 2.8 神煞给出「强在哪里、为什么强」

需求 ② 的最后一句：「根据神煞给出命主性格、指事的解释（强在哪里？为什么强？）」。

神煞不产生结论，它**解释已有的结论**。算法：

```
对人格层的每条结论 c（主导十神、过旺五行、某宫得力…）：
  1. 找出支撑 c 的载体集合 S（如「正官主导」→ 全部正官载体）
  2. 取落在 S 所在宫位上的神煞
  3. 按以下顺序排列作为解释素材：
       tone = strengthened / activated 者优先
       narrativeTags 与 c 的特质词有交集者优先
       其余按 hostWeight 降序
  4. 叙述形如：「{结论}。该{宫位}另见{神煞}，传统上与{标签}一类语汇相联系。」
```

「为什么强」的答案来自**力量层**（通根、司令、透干、得生），
神煞只补「传统上此处还被赋予什么含义」。二者在叙述中分句，不混。

## 3. 生命曲线（需求 ③）

### 3.1 即时盘

```
evaluateAt(base, { luckStep, elapsedYears, annualPillar, fleetingMonth })
```

- 权重来源：四柱（复用 base.l1）+ 大运 + 流年
- **流月只入符号层**，不参与权重 —— 硬约束不变
- 结构与生克全局重算（§1.0）
- 输出携带指回 `base` 的引用与逐载体 delta

### 3.2 追踪的序列

#### 3.2.1 权重类（可直接取自即时盘）

| 组 | 条数 | 内容 |
| 十神 | 10 | **生命十神曲线** |
| 五行 | 5 | |
| 宫位 | 8 | 各宫权重 |
| 日主 | 3 | 日主权重、同党占比、旺衰分档值 |
| 内外 | 2 | 显隐比 R、内外张力 T |
| 域 | 18 | 九域 ×（张力、净值） |
| 综合 | 3 | 单轮留存、流通度、顺逆指数 |

#### 3.2.2 每条序列同时给出绝对值与相对基础盘的偏离

```
q(t)         绝对值
q(t) − q_base 相对基础盘的偏离      ← 需求 ① 的「以基础盘为基准」
```

统计节点跑在**偏离序列**上，不跑在绝对值上 —— 前者的零点有意义。

#### 3.2.3 扰动类：命宫、胎元，以及各宫的「被引动程度」

命宫无权重，但有被引动的程度。对任一固定支 B（命宫支、胎元支、或某宫的支）：

```
扰动(B, t) = Σ over X ∈ {大运支, 流年支, 流月支} of
               关系强度(X, B) × 层级系数(X)

关系强度  冲 1.00 · 三合/三会 0.85 · 六合 0.70 · 刑 0.60 · 害 0.40 · 破 0.25
层级系数  大运 1.00 · 流年 0.85 · 流月 0.45
```

流月在这里**可以参与**，因为扰动是符号层的量，不是权重。
这正是「年月神煞入命」在曲线上的落法。

系数全部进参数表，标 `[校准]`。

### 3.3 采样：月度

你写的是「按照大运流年的时间（**年度/月度**）命盘」。采月度，理由是曲线本来就是连续的：

- **流年**是阶跃：立春换柱
- **大运**是连续斜坡：天干占比自 0.70 线性降到 0.30，
  每年约有 5.2 个单位的力量从天干移向地支
- **结构的结局也在运内变化**：冲的强弱比会穿过 1.20 / 2.50 门槛（§1.0 反例二）

所以年度采样会把运内的连续变化整个抹掉。改为**每月一个采样点**：

```
60 年 × 12 = 720 点
120 年 × 12 = 1440 点
```

**流月仍不参与权重** —— 曲线之所以在月度上有变化，是因为大运份额在连续推移，
不是因为流月加了分。这一点必须在报告里写明，否则读者会误以为流月在加权。

成本：一次即时盘约 1.2 ms，720 点约 0.9 秒（基础盘只算一次）。
可接受，但**须实测确认**，且 Web 端应放进 Worker 或首次进入曲线页时算一次并缓存。

> **不能按（大运, 流年）缓存结构检测**：冲的裁决依赖相对权重，
> 而权重逐月推移。缓存会把「运内结局翻转」这个真实现象抹掉。

## 4. 统计节点（需求 ③）

### 4.1 两个量

你的原话：「高于和低于的偏离都会造成变化，表示的是**变化率和变化量**」。

```
变化量  z(t)  = (q(t) − μ) / σ                 水平偏离
变化率  ż(t)  = (q(t) − q(t−Δ)) / σ_Δ          一阶差分的偏离
```

μ、σ 取该指标在**基准窗**内的算术平均与标准差；σ_Δ 为一阶差分序列的标准差。

**节点判据**：`max(|z|, |ż|) ≥ θ`。三种形态分别标注：

| 形态 | 判据 | 含义 |
| **持续极端** | 高 \|z\|、低 \|ż\| | 长期处于偏离态 |
| **急速穿越** | 低 \|z\|、高 \|ż\| | 量不极端但变得很快 —— 换运前后的典型形态 |
| **突入极端** | 两者皆高 | 最强 |

只报一个合成分数，会把「一直如此」与「突然变成这样」混为一谈。

### 4.2 三个尺度

| 节点 | 序列 | 基准窗 | 回答 |
| **小** | 月值 | 所在大运的 120 个月 | 这个月在**本运中**有多异常 |
| **中** | 大运步均值（每步一值） | 起运后 60 年的 6 步 | 这一步运在**一生中**有多异常 |
| **大** | 月值 | 起运后 60 年的 720 个月 | 这个时点在**一生中**有多异常 |

### 4.3 ⚠️ 中节点必须用稳健估计

样本量只有 6。样本标准差极不稳 —— 任何一步稍偏都会被放大成 2σ，
中节点近乎恒有产出，也就等于没有产出。

```
M   = median(x)
MAD = median(|x − M|)
稳健 z = 0.6745 × (x − M) / MAD
```

0.6745 = Φ⁻¹(0.75)，使 MAD 在正态下等于 σ。
若 `MAD = 0`（六步全同），该指标**不产出中节点**，不做任何回退 ——
没有散布就没有偏离可言。

### 4.4 节点 = 2σ 穿越区间，不是孤立时点

你写的是「得到和 2sigma 的**时间交点**」—— 交点，不是峰值。这个说法更准确，采纳。

```
穿越区间 = |z| ≥ θ 的极大连续区间
  t_in    进入点（曲线与 θ 线的交点，相邻采样点间线性插值）
  t_peak  区间内 |z| 的极值点
  t_out   离开点
  持续     t_out − t_in
  面积     ∫|z|dt 超出 θ 的部分       ← 「变化量」的积分形态
```

报「2031 年 3 月至 2033 年 8 月，2032 年 5 月最甚」，
比报「2032 年」既准确、又不给虚假的时点精度。

**插值只到月**。月度采样下线性插值到月内某一天是伪精度 —— 序列本身
在月内并无独立信息（流月不加权）。所以交点一律取整到月。

### 4.5 方向不定吉凶，但要标出

`z > 0` 与 `z < 0` **都是节点**。是机会还是压力，取决于指标与用忌的关系：

```
指标属用神向（用神/喜神的十神或五行）：z > 0 → 偏机会    z < 0 → 偏压力
指标属忌神向（忌神/仇神）：            z > 0 → 偏压力    z < 0 → 偏机会
宫位权重 / 宫位扰动：                  不判方向，只报「该宫变动」
域张力：                               **恒不判方向**
```

**域张力恒不判方向**：张力本身就是「顺逆并存」的度量，
给它定吉凶等于把已经拆开的东西又合回去 —— 那正是 tension 存在的理由。

### 4.6 神煞作为「异常的理由」

节点检出**之后**，在 `t_in` 前后一个月的窗口内取即时盘的符号层，
筛出满足以下之一者作为理由：

```
1. 神煞的 tone 为 activated（被引动）
2. 神煞落在本节点涉及的宫位上
3. 神煞的域标签与本节点的域重叠
4. 该窗口内新出现的结构事件（三合成局、冲、刑、开库…）
5. 该窗口内新触发的应期规则
```

按「与 t_in 的时间距离」升序排列 —— **最靠近进入点的，最像是引发它的**。

叙述形如：

> 2031 年 3 月起，官杀曲线进入偏离区（z = 2.3，持续至 2033 年 8 月，
> 2032 年 5 月最甚 z = 3.1）。同期流年支冲日支，配偶宫的驿马被引动，
> 大运支与本命月支三合成局。传统上这三项与变动、迁移一类语汇相联系。

注意末句的形状：**结构事实在前，传统语汇在后，中间不加因果连接词。**

### 4.7 五行指事在节点上的复用

需求 ③ 末句：「五行指事对应的身体易感部位一样可以提出」。

复用 §2.7 的两张固定表，只是取的五行来自节点而非基础盘：

```
当某个五行序列进入偏离区（无论偏高或偏低）：
  「该时段{element}偏离常态（z = {z}）。传统上{element}对应{脏}与{腑}。
   此处只陈述传统对照与盘面事实，不构成任何关于身体状况的判断；
   健康相关的决定请咨询持证专业人士。」
```

§2.7.4 的三条硬约束**同样适用**，无例外。
