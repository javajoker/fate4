## 4. 五行生克

```
相生：木 → 火 → 土 → 金 → 水 → 木
相克：木 → 土 → 水 → 火 → 金 → 木
```

以载体 `i` 对载体 `j` 的关系枚举（`i` 为施方）：

| `elem(i)` 对 `elem(j)` | 关系 | L3 核 |
| --- | --- | --- |
| i 生 j | `SHENG` | `+kernel.sheng` 加于 j，`−kernel.sheng × conservation.shengDrain` 减于 i |
| i 克 j | `KE` | `−kernel.ke` 减于 j，`−kernel.ke × conservation.keCost` 减于 i |
| i = j | `TONG` | `+kernel.tongdang` 加于 j |
| j 生 i | `SHENG` 的反向 | 不在 i→j 方向计，由 j→i 方向计 |
| j 克 i | `KE` 的反向 | 同上 |

**方向性是本系统的硬约束**：只计 `i → j` 的正向作用，反向由遍历另一有序对得到。不得在同一次遍历里同时加「泄」和「耗」，否则重复计数。

## 5. 十神

以日主 `dm` 为基准，对任一载体 `c`：

| `elem` 关系 | 同阴阳 | 异阴阳 |
| --- | --- | --- |
| `elem(c) == elem(dm)` | 比肩 | 劫财 |
| `elem(dm)` 生 `elem(c)` | 食神 | 伤官 |
| `elem(dm)` 克 `elem(c)` | 偏财 | 正财 |
| `elem(c)` 克 `elem(dm)` | 七杀 | 正官 |
| `elem(c)` 生 `elem(dm)` | 偏印 | 正印 |

分组：

- **同党** = 比肩 + 劫财 + 正印 + 偏印
- **异党** = 食神 + 伤官 + 正财 + 偏财 + 正官 + 七杀
- **四吉神** = 正官 · 正财偏财 · 正印 · 食神（顺用）
- **四凶神** = 七杀 · 伤官 · 偏印 · 羊刃（逆用）

**注意**：司令天干**可能不在该支的藏干表内** —— 首段司令往往是上月本气的余绪，未必是本支所藏。
经穷举，十二支中有 **5 支** 如此：

| 支 | 首段司令 | 本支藏干 | 同五行回退 |
| --- | --- | --- | --- |
| 子 | 壬 | 癸 | 壬 → 癸 ✔ |
| 卯 | 甲 | 乙 | 甲 → 乙 ✔ |
| 午 | 丙 | 丁 己 | 丙 → 丁 ✔ |
| 酉 | 庚 | 辛 | 庚 → 辛 ✔ |
| **亥** | **戊** | **壬 甲** | **无土可着 ✘** |

前四支皆为四正，司令干与本气同五行而异阴阳，回退可解。

**亥是唯一无解的一支。**亥月前 7 日戊土司令，是戌月土气的余绪；而亥只藏壬甲，同五行回退亦落空。
此即下文规则 3 所指的 `siling-unresolvable`，且仅此一例 —— 由 `test/tables.spec.ts` 穷举断言。

因此 `weights.monthCommand.silingBoost` 在亥月前 7 日出生者身上**不产生任何加成**，
月支三藏干按标准比例分配。这不是缺陷，是该支气机的真实写照：土气虽当令，亥中却无土可承。

由此还得出一条可断言的结构关系：**司令段数 = 藏干数 + （首段司令不在藏干中则 1）**。

**本系统的解析规则**（`weights.monthCommand.silingResolution`）：

1. 若司令干在该支藏干中 → 直接给该藏干加 `silingBoost`。
2. 若不在 → 回退到**同五行**的藏干加 `silingBoost`（壬→癸、甲→乙、丙→丁、庚→辛）。
3. 若同五行也无 → 不加 boost，记 `trace.note = 'siling-unresolvable'`。

加 boost 后，该月支的所有藏干在组内**重新归一**，使月支总分不变。

`weights.monthCommand.silingPolarityOverride`（默认 `false`）：若开启，司令期内该藏干的阴阳临时按司令干取（癸→壬的阳性）。默认关闭，避免十神在同月内翻转造成解释不稳定。
