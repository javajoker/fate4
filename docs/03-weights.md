# 03 · L1 配重模型

L1 把排盘结果转成一组带初始权重的载体。**此层不做任何生克判断**——它只回答「谁在场、各占多少分」。

---

## 1. 柱基准

| 柱 | 基准总量 | 说明 |
| --- | --- | --- |
| 年 | 100 | |
| 月 | 100 → 经月提放大 | 见 §3 |
| 日 | 100 | |
| 时 | 100 | 时辰未知则为 0，不补偿 |
| 大运 | **130** | 十年环境，力量大于任一本命柱 |
| 流年 | **110** | 太岁君临，仅当年有效 |
| 胎元 | 40 | 默认不启用（`weights.includeTaiyuan = false`） |

## 2. 干支拆分

**本命四柱：天干 40 : 地支 60。**

```
stemWeight   = pillarBase × weights.stemShare      // 100 × 0.40 = 40
branchWeight = pillarBase × weights.branchShare    // 100 × 0.60 = 60
```

地支不是载体，它把 `branchWeight` 按藏干个数下发：

```
hidden[k].weight = branchWeight × hiddenSplit[count][k]
```

| 藏干数 | 比例 | 60 分下发结果 |
| --- | --- | --- |
| 1（子卯酉） | `[1.00]` | `[60]` |
| 2（午亥） | `[0.70, 0.30]` | `[42, 18]` |
| 3（其余七支） | `[0.65, 0.25, 0.10]` | `[39, 15, 6]` |

三藏支的余气只有 6 分——微弱但非零。这是刻意的：戌中丁火不能忽略（火库），但也绝不能与本气戊土同量级。

## 3. 月提放大

月支当令，是全局旺衰的第一决定因素。

```
月支总量 = 60 × weights.monthCommand.branchMultiplier   // × 2.00 = 120
月干总量 = 40 × weights.monthCommand.stemMultiplier     // × 1.20 = 48
```

月柱合计 168。本命四柱总量 `100 + 168 + 100 + 100 = 468`，月柱占 **35.9%** —— 落在传统「月令定五分」到「月令三分之一」的合理区间内。

**为何天干也放大但幅度小**：月干得月令之气而透，比其他柱的天干有根气，但天干终究是「虚」，不应与月支同比例。1.20 是保守取值。

## 4. 司令分野修正

司令表见 [01-foundations](01-foundations.md) §10。

```
1. 由 birthJdUT 距节的天数定 segment ∈ {0,1,2} 与司令干（皆为绝对时刻，见 02-chart §2.4）
2. 解析司令干 → 月支中的某个藏干（同字 → 同五行 → 无解则跳过）
3. 该藏干 weight ×= weights.monthCommand.silingBoost   // 1.50
4. 月支所有藏干在组内重新归一，使月支总量仍为 120
```

**示例**：出生于寅月第 3 日（`segment=0`，司令戊土）。

| 藏干 | 归一前 | 司令加成 | 重归一后 |
| --- | --- | --- | --- |
| 甲（本气） | 78 | 78 | 66.1 |
| 丙（中气） | 30 | 30 | 25.4 |
| 戊（余气） | 12 | 12 × 1.5 = 18 | 15.3 |
| 合计 | 120 | 126 | **120** ✔ |

余气戊从 12 升到 15.3，甲从 78 降到 66.1。这准确反映了「立春头几日，土气未退，木气未专」。

若同一人生于寅月第 25 日（`segment=2`，司令甲木），则甲得 1.5 倍加成，末位数值反向拉开。同一个月支，月初与月末的力量结构因此不同——这是精确排盘的意义所在。

## 5. 大运权重的经年变化

大运总量恒为 130，但**干支内部分配随交运后经过的时间连续变化**。

```
elapsed = (当前瞬时 − 交运时刻) / 回归年     // ∈ [0, 10)
t       = elapsed / 10                        // ∈ [0, 1)

stemShare(t) = luck.stemShareStart + (luck.stemShareEnd − luck.stemShareStart) × t
             = 0.70 − 0.40 t

luckStemWeight   = 130 × stemShare(t)
luckBranchWeight = 130 × (1 − stemShare(t))
```

| 经过年数 | t | 天干占比 | 天干分 | 地支分 |
| --- | --- | --- | --- | --- |
| 0（刚交运） | 0.00 | 0.700 | 91.0 | 39.0 |
| 2.5 | 0.25 | 0.600 | 78.0 | 52.0 |
| **5.0** | **0.50** | **0.500** | **65.0** | **65.0** |
| 7.5 | 0.75 | 0.400 | 52.0 | 78.0 |
| 10（换运前夕） | ~1.00 | 0.300 | 39.0 | 91.0 |

**交叉点恰在第 5 年末**，符合「一运十年，前五年重天干，后五年重地支」。与传统的硬切分不同，本模型是连续的——同一步大运的第 4 年与第 6 年因此呈现渐变而非突变的气象，避免了在运程曲线上制造人为的阶跃。

**阶梯模式** `luck.mode = 'step'`（对照用）：

```
elapsed < 5 → stemShare = 0.65
elapsed ≥ 5 → stemShare = 0.35
```

**注意**：`elapsed` 以**交运时刻**起算，不是虚岁，也不是立春。交运在 3 月 12 日的人，其大运第 5 年末落在 5 年后的 3 月 12 日，与流年边界无关。

地支拿到 `luckBranchWeight` 后，同样按 §2 的藏干比例下发。

## 6. 流年权重

流年总量 110，**干支为固定的 40 : 70**（注意：不是本命的 40:60 比例）。

```
annualStemWeight   = weights.year.stem     // 40
annualBranchWeight = weights.year.branch   // 70
```

太岁地支的权重刻意高于按 40:60 比例应得的 66 —— 太岁以支为体，其冲合刑害的引动作用主要由地支承担。

`weights.year.stemBranchSwing`（默认 `false`）：开启后流年内部也做上下半年的干支主次切换。传统少用，仅作实验开关。

## 7. 空亡

```
weights.kongwang:
  enabled: true
  factor: 0.80              # 空亡地支的藏干整体打折
  releasedByChong: true     # 逢冲则实（填实）
  releasedByHe: true        # 逢合则实
  applyToLuckAnnual: false  # 大运流年不论空亡
```

处理时机在 L1 末尾，但 §「逢冲逢合则解空」的判定依赖 L2 —— 因此实现上分两步：L1 打上 `KONGWANG` 标记与待定折扣，L2 结束后统一结算。若该支在 L2 中参与了任何合或冲，撤销折扣并改标记为 `KONGWANG_FILLED`。

## 8. 透干与通根：不额外加权

```
weights.revealedResonance: 1.00     # 默认关闭
```

「甲木通根寅木则强」这件事，本系统**不在 L1 用系数表达**，而是在 L3 由距离模型自然产生：同柱天干与地支藏干的距离系数为 1.00（最强），因此坐下有根的天干在传导中持续获得同党帮扶，权重自然抬升。

在 L1 再加一个透干系数会**重复计入同一效应**。参数保留为 1.00 并有文档说明，是为了让日后想做对照实验的人知道这里被刻意留空了，而不是被遗忘了。

同理，**日支不额外加权**。日主坐下之支的特殊重要性同样由距离模型（同柱 D=1.00）表达。

## 8.5 默认值的真源

`params/default.yaml` **不是**默认值的真源 —— 真源是 `packages/core/src/params/defaults.ts`。

理由：core 需在浏览器、Node、Worker 中跑同一份代码且零运行时依赖，
读 YAML 要么引入解析器，要么加一道代码生成；TS 作真源则天然有编译期类型保证。

YAML 保留为平行的文档表述，由 `test/params.spec.ts` 断言**逐键一致**
（键集合相同、值逐项相同）。任一处漂移即构建失败，文档不会悄悄过期。
这与干支表采用的是同一条纪律：两份独立表述必须吻合。

参数校验分两类，语义不同，不可合并：

| 类别 | 内容 | 违反后果 |
| --- | --- | --- |
| 区间与枚举 | 单个值是否落在允许范围 | 多半会在别处炸出来 |
| **结构不变量** | 值与值之间必须成立的关系 | **静默产出错误盘面** |

后者才是真正危险的一类，故在 `loadParams` 入口一次报出全部错误，绝不静默取默认。
当前的结构不变量：干支占比之和为 1、藏干下发比例之和为 1 且递减、流年干支之和等于其总量。

## 10. L1 不变量（写成断言）

1. 每个本命柱的 `stemWeight + Σ branchHidden = pillarBase`，月柱除外（= 168）。
2. 司令重归一后，月支藏干之和 **精确等于** 120（浮点误差 < 1e-9）。
3. 大运干支之和恒为 130，与 `elapsed` 无关。
4. 流年干支之和恒为 110。
5. 所有 `weight ≥ 0`。
6. 载体数：本命四柱 4 天干 + Σ藏干（8–12 个）= 12–16 个；加大运流年后 18–24 个。
7. 每个载体至少有一条 `trace` 记录其初始赋值。
