# 中土 · 三式（六壬 · 奇门 · 太乙）

> ⚠️ 本页年代、作者、书名**未经实体书核对**。

「三式」指大六壬、奇门遁甲、太乙神数，旧称「三式之学」。
三者共同的特征是**式盘**：一个可转动的天盘压在固定的地盘上，
转到某个角度读出结果。这是一种**器物**上的传统，不只是文本上的。

## 大六壬

| | |
| --- | --- |
| **物证** | 汉代墓葬出土式盘可证式占之制已行（如安徽阜阳双古堆汉墓所出） |
| **主要典籍** | 《六壬大全》（明，收入《四库全书》）、《大六壬毕法赋》、《六壬指南》 |
| **托名** | 更早的归属属托名 |

### 它的天文含量比看上去高

- **月将**每**中气**一换。而中气的定义黄经是 30° 的整数倍 ——
  也就是西方黄道十二宫的入宫点。**月将就是太阳所在的宫**，换了一套地支名字。
- **月将加时**：把月将（太阳位置）叠到时辰上转出天盘，
  是一个朴素但真实的天球模型 —— 天左旋、地不动，太阳每月退一宫。

这一条由 [`compare/substrate.ts`](../packages/core/src/compare/substrate.ts)
逐条验证（`YUEJIANG_ZODIAC`）。

### 本项目的实现与存疑

实现在 [`liuren/`](../packages/core/src/liuren/)，十一种课体全覆盖。
⚠️ 待核对：**别责、八专、伏吟的取法**与**涉害的深浅计算**，各家不一。

## 奇门遁甲

| | |
| --- | --- |
| **托名** | 黄帝、风后 —— 传说，不作年代用 |
| **物证** | 汉代有太乙九宫占盘出土，与九宫之制相关 |
| **核心歌诀** | 《烟波钓叟歌》（托名）；另有《奇门遁甲元灵经》等 |

定局要看**节气三元**（上元、中元、下元），这一层是历法派生的；
其余（九宫飞布、三奇六仪、八门八神）是约定。

实现在 [`qimen/`](../packages/core/src/qimen/)，时家转盘，十八局全覆盖。
⚠️ 待核对：**节气三元的局数表**（24 × 3 = 72 个数字），凭记忆转录。
