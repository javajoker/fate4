# 中土 · 星命（紫微斗数 · 七政四余）

> ⚠️ 本页年代、作者、书名**未经实体书核对**。

这两套常被并称「星命」，但它们的**天文含量差得极远** ——
一个的星是真的，一个的星不是。这是本页最该带走的一件事。

## 紫微斗数

| | |
| --- | --- |
| **托名** | 陈抟（北宋初，约 871–989） |
| **可考** | 现存最早为明代《紫微斗数全书》（托名陈抟，罗洪先编）。一般认为成型于明 |
| **另一支** | 《十八飞星策天紫微斗数》 |

### ⚠️ 它的「星」不是天上的星

这是最容易被误解的一点，也是它与七政四余的根本分别：

- **紫微、天府、贪狼、廉贞……** 是按**农历日与时辰的算术规则**
  摆进十二宫的**虚星**。
- 真正的紫微垣（北极一带的星官）**一次都不进计算**。
- 起盘不需要星历，只需要农历日期。

它的天文含量**全在农历**：朔日定初一要真算合朔，置闰要看中气，
而中气是太阳黄经的 30° 整数倍。所以它是「历法派生」，不是「实测天体」。

这个区分不是贬低。虚星体系自有其一致性，而且它**可复算**——
问题只在于，把它说成「观星」是不对的。

**本项目现已实现紫微斗数的排盘与盘面解读**（十二宫、十四主星、六吉六煞、四化、大限，以及三方四正与空宫借星）。⚠️ **星曜庙旺表（168 格）未收录** —— 那是缺口不是取舍，收齐需要一个底本。见 `docs/17-ziwei.md`。
（[`compare/correspondence.ts`](../packages/core/src/compare/correspondence.ts)
的 `ziweiPalaces`）—— 因为那一步正是「它的天文含量在哪」这个问题的直接证据：

```
自寅起正月，顺数至生月；再自该宫起子时，逆数至生时  →  命宫
```

输入只有农历月与时辰两个整数。穷举 12 × 12 = 144 种输入，
落到 **12 个命宫、72 对（命宫, 身宫）**—— 整整折半，
因为 `(命 + 身) mod 12` 恒等于两倍的月宫。这是一条可验证的不变量。

## 七政四余

| | |
| --- | --- |
| **来历** | 唐代随佛经与西域历法传入。《七曜攘灾决》《都利聿斯经》为其迹 |
| **主要典籍** | 《果老星宗》《张果星宗》 |

「七政」指日、月、五星；「四余」指紫炁、月孛、罗睺、计都
（后两者是黄白交点，前两者的来历各家说法不一）。

### 它与西洋占星同源

**输入直接是日月五星的实际位置** —— 要算星历才起得了盘。
这与西洋占星是同一类东西，而与紫微斗数不是。

中土传统里，七政四余与子平、紫微分属不同的路子：
前者测天，后者用历法。清代以降七政四余式微，子平与紫微盛行 ——
一个可能的原因是后两者**不需要星历**，门槛低得多。

**本项目现已实现七政四余**：七政（日月五星）的视黄经由 VSOP87D 算出，四余取月亮的升交点、降交点与远地点，十二宫配地支，并给庙旺陷落平五档。

⚠️ 庙旺表与西洋古典那张**七格全同**，但这不能拿来论证「东西方独立得出同一张表」——七政四余唐代随佛经入华，与希腊化同源，而本项目这张表的转录者读过西洋那张。见 `docs/16-sky.md` §6。
