# 中土 · 卜筮（六爻 · 梅花 · 周易本经）

> ⚠️ 本页年代、作者、书名**未经实体书核对**。

## 《周易》本经

六十四卦的卦辞与爻辞。公有领域，文本高度标准化 —— 这是本页唯一
**不需要标「待核对」**的部分：它的传世文本两千年来差异极小，
且有大量互校本。

本项目把它作为**指事**引入（见 [`docs/13-liuyao.md`](../docs/13-liuyao.md) §7.5），
语料记在 [`packages/data/src/yaoci/`](../packages/data/src/yaoci/)，
源文件 SHA256 记在 `provenance.ts`。

> 要紧的区分：**爻辞属于象辞一路，与纳甲断法是两套系统。**
> 京房一路断卦从不引爻辞；把两者并读是民间的用法。
> 本项目因此把爻辞单列一层，不参与判断。

## 六爻（纳甲）

| | |
| --- | --- |
| **纳甲之法** | 归于西汉 · **京房**（前 77–前 37）。把干支配进六爻，于是卦有了五行与六亲 |
| **较早的断法专书** | 《火珠林》（托名麻衣道者，宋） |
| **清代集成** | 《卜筮正宗》（王洪绪）、《增删卜易》（野鹤老人） |

《增删卜易》一路主张**专取用神、不杂神煞**，与《卜筮正宗》的取向有别。
本项目的断法偏向前者：只看六亲、生克、旺衰、空破，不以神煞断卦。

实现在 [`liuyao/`](../packages/core/src/liuyao/)。

### 八宫是推出来的，不是抄的

六十四卦的京房八宫归属，本项目**按规则生成**：
本宫 → 一世 → 二世 → 三世 → 四世 → 五世 → 游魂 → 归魂。
推出来的 64 个恰好是全部 64 个 —— 这件事本身就是一条校验，
规则若写错必然出现重复或缺漏。

## 梅花易数

| | |
| --- | --- |
| **托名** | 北宋 · 邵雍（1011–1077） |
| **实际** | 托名之作，成书晚于邵雍；现存本多为明清刊本 |

起卦法三种：按时、报数、观物。本项目实现前两种。

⚠️ 一处常被说错的事：**单数报数法在一个时辰内只有 24 种结果**，
不是 48，也不是 384。上卦、下卦、动爻全由那一个数决定，
而 8 与 6 不互素，周期是 lcm(8, 6) = 24。
本项目在界面上明说这件事，并建议要全覆盖就用两数或掷钱。
