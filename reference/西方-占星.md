# 西方 · 占星

> ⚠️ 本页年代、人名**未经实体书核对**，但这一支的年代学比中土那几支可靠得多：
> 有连续的文本传承与大量现代学术研究。

## 源流

| | |
| --- | --- |
| **源头** | 巴比伦的天象记录与预兆文献。最初是**国事占**，不占个人 |
| **个人星盘的出现** | 希腊化时期。现存最早的个人出生盘属公元前 5 世纪末前后的巴比伦，希腊化埃及把它系统化 |
| **集成** | 托勒密《四书》（*Tetrabiblos*，2 世纪）。同一人写的《天文学大成》（*Almagest*）是当时最好的天文学著作 —— **星历与占星出自同一支笔**，这件事值得注意 |
| **近代** | William Lilly, *Christian Astrology*（1647）；17 世纪后在欧洲学界边缘化；20 世纪以心理学语汇复兴 |

托勒密那件事值得多说一句：在他那个时代，**算天与断事不分家**。
分家是后来的事 —— 而分家之后，占星保留了算天的那套工具，
却不再更新它的理论基础。

## 回归 vs 恒星：同一把尺，两种零点

这是占星内部最大的分歧，而且**它是一个天文问题，不是信仰问题**。

| | 零点 | 用它的 |
| --- | --- | --- |
| **回归**（tropical） | **春分点**，即黄经 0° | 西方主流 |
| **恒星**（sidereal） | 某颗恒星（常取室女座 α，Chitra / Spica） | 印度（Jyotiṣa）主流 |

春分点因**岁差**每年西移约 50.3 角秒。两套零点因此逐年拉开，
当代相差约 **24°** —— 差不多整整一个宫。

> 这意味着：同一个人，回归派说他太阳在白羊，恒星派可能说在双鱼。
> 不是谁算错了，是两套坐标系。

岁差由**喜帕恰斯**（Hipparchus）约公元前 127 年发现，
正是通过比对自己与前人的恒星黄经记录。

### 本项目算了这件事

[`compare/substrate.ts`](../packages/core/src/compare/substrate.ts)：

- `precessionSinceJ2000` 取 IAU 2006 的 `p_A` 前两项
- `ayanamsaAt` 把零点作为**参数**，不替人选派别
- 代入 Lahiri 一派常用的零点，算出当代约 **24.24°**，与各星历软件相符

### 中土的节气是回归的

二十四节气按**太阳黄经**定义，而黄经以春分点起算 ——
所以四柱、六壬、紫微的历法基底与西方的**回归派同源**，与恒星派不同源。

这是定义的直接后果，不是立场。

## 与中土的那条实打实的连接

十二宫的入宫点（黄经 0°、30°、60°……）与中土的十二**中气**
是**同一组时刻**。逐格验证，无一例外。

而中土的十二**节**落在它们的正中间，偏移恰好 15°；四柱的月建由节划分。
故四柱与西洋占星在月这一层用的是同一把尺，零点差半格。
