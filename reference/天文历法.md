# 天文历法

这一页与其余几页性质不同：**这里的东西有权威版本，可以核对，也已经核对过。**

其余几页记的是「某书大约成于某朝」，这一页记的是「某个数来自哪个档案、
SHA256 是多少」。这个差别正是本项目反复在守的那条线 ——
[排盘可验证，断论不可验证](../book/03-排盘.md)。

## 太阳位置：VSOP87D

| | |
| --- | --- |
| **用途** | 二十四节气（太阳视黄经到达 15° 整数倍的时刻）、真太阳时的均时差 |
| **来源** | VSOP87D 官方档案，地球部分（`VSOP87D.ear`） |
| **取法** | 由 [`scripts/generate-vsop87.mjs`](../scripts/generate-vsop87.mjs) 从**两个互相独立的来源**取回 —— 法国 IMCCE（巴黎天文台）与 CDS/VizieR（斯特拉斯堡）—— 字节完全相同方才采信 |
| **校验** | SHA256 固化在生成器里，取回不符立即中止 |
| **截断** | 按给定阈值截断，残差记在 [`provenance.ts`](../packages/data/src/vsop87/provenance.ts) |

**数字全程没有经过任何人工或模型转述。** 抄错一位在节气时刻上就是几分钟的
系统偏差，而且不会被任何结构性测试发现。

### 实测精度

对**香港天文台**公布的 2019–2028 共 240 个节气时刻：

| 算法 | 最大偏差 | 均方根 | 超 60 秒 |
| --- | --- | --- | --- |
| **VSOP87D（本项目）** | **42.2 秒** | 18.0 秒 | **0 条** |
| Meeus 简化解（对照） | 800.6 秒 | 328.8 秒 | 213 条 |

对照组不是稻草人：简化解是不少开源排盘库在用的算法。

## ΔT（力学时与世界时之差）

节气要算到秒，就绕不开 ΔT。本项目用的是分段多项式拟合
（[`astro/deltaT.ts`](../packages/core/src/astro/deltaT.ts)）。
历史时期的 ΔT 本身有观测不确定性，这一项的误差在远离当代时会增大 ——
这是方法的性质，不是实现的疏漏。

## 岁差：IAU 2006

| | |
| --- | --- |
| **用途** | 回归黄道与恒星黄道之差（ayanamsa）的计算 |
| **取法** | IAU 2006 的黄道总岁差 `p_A`，取前两项：`5028.796195″·T + 1.1054348″·T²` |
| **截断** | 三次项在 ±2000 年内不足 0.01°；本模块只用来看量级与趋势，不做星历 |
| **交叉验证** | 代入 Lahiri 一派常用的零点，算出当代 ayanamsa ≈ 24.24°，与各星历软件的 ~24.2° 相符 |

那条交叉验证是有意为之：ayanamsa 的值可以在别处独立查到，
故它反过来能验证这段岁差算法没有跑偏。

## 节气静态表

1900–2100 共 4824 个节气时刻预计算并内置（约 40 KB gzip），
区间外走实时 VSOP87 计算。表与实时计算的一致性由测试断言。

## 时区与真太阳时

真太阳时 = 区时 + 经度差 + 均时差 − 夏令时。三项都算，并在输出里逐项回显。
夏令时按 IANA 时区数据库处理（中国 1986–1991 年实行过）。

## 交叉校验：Astronomy Engine

| | |
| --- | --- |
| 仓库 | [cosinekitty/astronomy](https://github.com/cosinekitty/astronomy)，**MIT** |
| 位置 | `reference/vendor/astronomy-engine`（git submodule，`--depth 1`） |
| 用途 | **只在测试里**与本项目的太阳、月亮位置逐点对照。不进任何运行时路径 |

一个实现可以**自洽地错下去** —— 系数抄错一位、章动符号写反、历元弄混，
这些都不会被任何内部不变量逮到，因为内部不变量只看自己。
节气那一侧已经对过香港天文台的 240 个公布值；这个子模块补上的是
**月亮**与**任意时刻的太阳**，那两样没有现成的公布表可查。

实测（1900–2099 共 11 个时刻）：

| 量 | 两套实现的最大差 |
| --- | --- |
| 太阳视黄经 | **1.5 角秒** |
| 月亮视黄经 | **3.2 角秒** |

子模块未初始化时该组测试自动跳过 —— 一个因为缺少可选校验而变红的套件，
只会教人去忽略红色。

## 其它用到的天文量

| 量 | 取法 | 用在哪 |
| --- | --- | --- |
| **月亮升交点** | Meeus 第 47 章平根多项式 | 四余的罗睺／计都（= 西洋占星的 North／South Node） |
| **月亮近地点** | 月亮平黄经 − 平近点角，同一组根数 | 四余的月孛（= Black Moon Lilith 平根版） |
| **木星恒星周期** | 11.862615 年 | 太岁与岁星的漂移 —— 约 86 年跳一个「次」 |
| **平气间隔** | 回归年 / 24 = 15.2184 天 | 与定气对比 —— 1645 年《时宪历》前后的那条缝 |

交点周期算出 18.61 年、近地点周期 8.85 年，与公认值相符 ——
这两个数可以独立查到，故它们反过来验证了这段实现。
见 [`compare/correspondence.ts`](../packages/core/src/compare/correspondence.ts)。
