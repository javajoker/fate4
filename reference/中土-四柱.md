# 中土 · 四柱（子平）

> ⚠️ 本页年代、作者、书名**未经实体书核对**。可用来定位，不可当考据结论引。

## 源流

| | |
| --- | --- |
| **可考的起点** | 唐 · **李虚中**（约 761–813）。以**年柱**为主推命，韩愈《殿中侍御史李君墓志铭》提到他「以人之始生年月日所直日辰支干，推人寿夭贵贱」—— 注意：**没有时柱** |
| **转折** | 五代宋初 · **徐子平**。改以**日干**为主，「子平」之名由此而来。四柱八字的格局自此定型 |
| **托名** | 更早的归属（如鬼谷子、珞琭子）属托名，不作年代用 |

从「年柱为主」到「日干为主」是一次**基准点的更换**，不是增补。
在此之前推的是「这一年生的人」，之后推的是「这个人」。

## 主要典籍

| 书 | 大致年代 | 性质 |
| --- | --- | --- |
| **《渊海子平》** | 现存为明刊本，托名宋 · 徐升辑 | 子平法的早期系统汇编。格局、十神、神煞大体在此定型 |
| **《三命通会》** | 明 · 万民英（万历年间） | 体量最大的一部，收入《四库全书》。兼收并蓄，内部说法并不统一 |
| **《滴天髓》** | 托名明初 · 刘基；通行注本为清 · 任铁樵《滴天髓阐微》 | 偏义理，讲气势流通，不重神煞。与《渊海》一路取向不同 |
| **《穷通宝鉴》** | 清 · 余春台辑，原名《栏江网》 | **调候**专书：十天干 × 十二月 = 120 格，每格指明该取什么 |
| **《子平真诠》** | 清 · 沈孝瞻 | 讲格局顺逆用法，条理最清 |

### 本项目用到的

- **调候**：《穷通宝鉴》通行本的 120 格，实现在
  [`conclude/tiaohou.ts`](../packages/core/src/conclude/tiaohou.ts)。
  ⚠️ **凭记忆转录，尚未经实体书核对**；31 格各家有异，8 格已列出不同版本。
  这是本项目已知最大的一处数据风险，记在
  [`docs/11-validation.md`](../docs/11-validation.md) 第 2 项。
- **格局顺逆与相神**：取向接近《子平真诠》一路。
- **藏干比例、月令放大、距离衰减**：**典籍里没有任何数字**。
  本项目填的那组写在 [`params/default.yaml`](../params/default.yaml) 并标了 `[校准]`。

## 几处各家不一的地方

这些在本项目里全部是参数，不是定论（见
[`docs/11-validation.md`](../docs/11-validation.md) 的待校准清单）：

| 分歧 | 两说 |
| --- | --- |
| **子时归哪一天** | 早晚子时（晚子归次日）／ 子正换日 ／ 子初换日 |
| **藏干比例** | 本气中气余气各占几成，无典籍数字；另有按日数分的司令分野一说 |
| **阴干长生** | 阳顺阴逆 ／ 阴阳同生同死 |
| **土的长生** | 火土同宫（土随火）／ 水土同宫（土随水） |
| **从格门槛** | 松紧差别极大，而从与不从的用神**正好相反** |

最后一条要紧：它不是精度问题，是**同一张盘两种相反读法**的问题。
