# 西方 · 塔罗

> ⚠️ 本页年代**未经实体书核对**，但塔罗的来历是本目录里**证据最硬**的一支 ——
> 它晚近、在欧洲、有实物与档案。

## 真实的来历

| 年代 | 事 |
| --- | --- |
| **15 世纪中叶** | 意大利北部（米兰、费拉拉）出现一种纸牌**游戏**，称 *trionfi*（后来的 tarocchi）。现存实物如 Visconti-Sforza 牌组（1440 年代） |
| **16–17 世纪** | 作为牌戏流行于意大利、法国。**没有占卜用途的记载** |
| **18 世纪** | 马赛牌（Tarot de Marseille）图式定型 |
| **1781** | Court de Gébelin 提出「源自古埃及」之说。**无任何证据支持**，但影响极大 |
| **1780 年代** | Etteilla 开始系统地把它用于占卜 —— 这是占卜用途**有据可查的起点** |
| **19 世纪中** | Éliphas Lévi 把塔罗与卡巴拉对应起来 |
| **1888 起** | 金色黎明（Golden Dawn）系统化了「牌 — 行星 — 星座 — 希伯来字母」的对应表 |
| **1909** | Rider–Waite–Smith 牌组出版，小阿卡纳首次全部配图，成为后世最通行的图式 |

## 两件要说清楚的事

### 一、天文含量为零

塔罗的起牌只需要**洗牌与切牌**。不需要时刻，不需要地点，不需要星历。

它是本比较模型里唯一一个「纯约定」档的系统 —— 这不是贬低，
是一个关于**输入**的事实陈述。

### 二、那层占星对应是后加的

流行的「权杖对应火、圣杯对应水」「皇帝对应白羊」这类对应表，
是 **19 世纪末金色黎明一系的注解**，不是塔罗的来历，也不进起牌。

把它当作「塔罗与占星同源」的证据，是把注解当成了本文。

> 这件事与中土的情形可以对照：《周易》爻辞与京房纳甲也是两套系统，
> 民间把它们并读。差别在于，爻辞与纳甲都在中土传统内部且年代相近；
> 而塔罗的占星对应是跨了四百年、从另一个体系嫁接过来的。

## 它在比较模型里的位置

| 轴 | 塔罗 |
| --- | --- |
| 输入 | 随机 + 问类。**不含时刻** |
| 天文含量 | 纯约定 |
| 确定性 | 随机 —— 同一时刻重抽结果不同 |
| 状态空间 | 离散且可数。三张含逆位 78 × 77 × 76 × 2³ = 3,651,648 |

**两刀都落单**：按天文含量它是唯一的「纯约定」，
按确定性它是唯一的纯「随机」。

而这意味着一件要紧的事：**它与其余几套不可比。**
确定性系统问的是「这个时刻的结构是什么」，可以复算、可以对质；
随机系统问的是「这一次抽到了什么」，复算没有意义。
把两者放进同一张「准确率」表里，是一个类别错误。

**本项目未实现塔罗。**
