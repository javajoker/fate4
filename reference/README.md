# reference —— 参考书目

这个目录放**书目与出处**，不放正文。

## 为什么单列一个目录

本项目有一条长期纪律：凡是转录来的东西，必须记下它从哪儿来
（见 [`docs/11-validation.md`](../docs/11-validation.md)）。
VSOP87 的系数记了 SHA256；爻辞语料记了源文件校验和；
而命理这一侧的典籍一直只在代码注释里零散提到 —— 那不够。

这个目录把它们集中起来，并且**把「可考」与「托名」分开记**。

## 三条纪律

**一、托名不是年代。**

这几套东西大多有一个传说的创立者（黄帝、陈抟、邵雍、麻衣道者），
和一个可考的最早文本，两者往往差几百上千年。把托名当年代写进书目，
是这个领域最常见的一种失实。本目录每一条都分两栏。

**二、没核对过就写明没核对过。**

下面的年代、作者、书名绝大多数**未经实体书核对**。它们足够用来定位一本书、
判断一个说法的大致来历，但**不能当考据结论引用**。
与《穷通宝鉴》那 120 格同样的性质：带着已知瑕疵的明确记录，
胜过听上去圆融的含混说法。

**三、不编版本信息。**

不写 ISBN、不写页码、不写具体出版社与印次 —— 这些若没有实物在手，
写出来就是编的，而编出来的版本信息比没有更坏：它看起来可核对。

## 与 `packages/core/src/compare/` 的关系

那个模块是这些书目的**可计算摘要**：每套系统的输入、天文含量、确定性、
状态空间，都在那里有一条带理由的登记，而且能跑。

书目说「这套东西是什么、从哪儿来」，模块说「它的可比属性是多少」。
两边都在 [`book-compare/`](../book-compare/) 那本书里汇到一处。
