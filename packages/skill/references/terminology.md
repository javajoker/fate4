# 术语对照

供解释名词之用。英文场景保留拼音 + 汉字 + 意译三重标注，例如
`Zheng Guan 正官 (Direct Officer)`。

## 十神

以日主为参照，其余天干与日主的关系。同党（生我、同我）与异党（我生、我克、克我）
的划分，是旺衰判定的直接依据。

| 十神 | 关系 | 英文 |
| --- | --- | --- |
| 比肩 | 同我，同性 | Bi Jian (Peer) |
| 劫财 | 同我，异性 | Jie Cai (Rob Wealth) |
| 食神 | 我生，同性 | Shi Shen (Eating God) |
| 伤官 | 我生，异性 | Shang Guan (Hurting Officer) |
| 偏财 | 我克，同性 | Pian Cai (Indirect Wealth) |
| 正财 | 我克，异性 | Zheng Cai (Direct Wealth) |
| 七杀 | 克我，同性 | Qi Sha (Seven Killings) |
| 正官 | 克我，异性 | Zheng Guan (Direct Officer) |
| 偏印 | 生我，同性 | Pian Yin (Indirect Resource) |
| 正印 | 生我，异性 | Zheng Yin (Direct Resource) |

同党 = 比肩 · 劫财 · 正印 · 偏印　异党 = 其余六者。

## 用神五组

| 术语 | 定义 | 英文 |
| --- | --- | --- |
| 用神 | 全盘取用之神 | Yong Shen (Useful God) |
| 喜神 | **生用神者** | Xi Shen (Favourable God) |
| 忌神 | **克用神者** | Ji Shen (Unfavourable God) |
| 仇神 | 生忌神者 | Chou Shen (Hostile God) |
| 闲神 | 其余 | Xian Shen (Neutral God) |

> 注意忌神的方向是「克用神者」，不是「用神所克者」。
> 用神为水时忌神是土（土克水）；水所克的火对水毫无威胁。

## 取用四法

| 法 | 何时用 | 英文 |
| --- | --- | --- |
| 调候 | 极端气候（冬月火弱、夏月水弱）时短路优先 | Tiao Hou (Climatic Adjustment) |
| 通关 | 两强相持且相克，取中间五行引流 | Tong Guan (Mediation) |
| 扶抑 | 主路，恒有产出 | Fu Yi (Support or Restraint) |
| 病药 | 后置精修：用神被伤到一定程度，改取制伤者 | Bing Yao (Ailment and Remedy) |

## 盘面

| 术语 | 说明 |
| --- | --- |
| 藏干 | 地支所含的天干。本气 > 中气 > 余气 |
| 司令 | 月支藏干中当月当权者，按入节日数分段 |
| 通根 | 天干在地支中有同五行藏干可依 |
| 空亡 | 六十甲子分六旬，每旬余两支为空 |
| 纳音 | 六十甲子的五行别称，如「路旁土」 |
| 胎元 | 受胎之月的干支，由月柱推得 |
| 命宫 | 由生月与生时推得的宫位。不参与配重 |

## 结构

| 术语 | 说明 |
| --- | --- |
| 三会 / 三合 / 半合 / 六合 | 地支的成局关系，优先级依次递减 |
| 合化 | 合而化成新五行。需月令支持与引化之神，且不被争合、不被冲 |
| 合绊 | 合而不化。双方仍在场、可被作用，但**向外施力打折**（贪合忘克） |
| 冲 / 刑 / 害 / 破 | 地支的损耗关系，强度依次递减 |
| 开库 | 辰戌丑未被冲或被刑，库中之物得以透出 |

## 时间层

| 术语 | 说明 |
| --- | --- |
| 大运 | 十年一步。前五年重天干、后五年重地支，二者恰在第 5 年末交叉 |
| 流年 | 太岁，一年之主 |
| 起运 | 自生日至交节的日数换算得来的入运年龄 |
| 顺逆指数 | 当年五行结构与本命喜用的契合度 ∈ (0,100)。**不是运气好坏** |
| 张力 | 同域内 min(Σ顺向, Σ逆向) / max(…)。越接近 1，该域变动越实质 |
| 应期 | 某结构在某时点被引动。**「应事」不等于「吉」或「凶」** |
