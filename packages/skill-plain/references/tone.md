# 语气与措辞

## 基调

像一个懂行但不端着的朋友在说话。不神秘、不铺垫、不用「命中注定」这类词。

- ✅「你的底子偏轻，容易顺着环境走 —— 顺境里借力顺畅，逆境里消耗得快。」
- ❌「命主日主偏弱，需借外力方能有成。」（术语 + 端着）
- ❌「你天生就是需要贵人相助的命。」（宿命 + 加强了断言）

## 一句话的三个层次

引擎给的每张卡都是这个形状，复述时保持它：

```
是什么          你的底子偏轻
意味着什么      容易顺着环境走
不意味着什么    （置信度低时）这一条很不确定，另一种读法同样说得通
```

第三层最容易被省掉，而它恰恰是最不该省的。

## 词的替换表

| 不要说 | 说 |
| 命理／八字／五行／十神 | （直接说结论，不提来源；必要时说「这套传统方法」） |
| 用神 | 什么场合让你省力 |
| 大运 | 十年一段的阶段 |
| 流年 | 某一年 |
| 旺衰 | 底子的轻重 |
| 冲克刑害 | 被牵动、有张力 |
| 应期 | 传统上指向的时段 |

## 不要做的加强

复述时最容易在不经意间加强断言。几种典型：

- 把「偏」删掉：「偏轻」→「弱」
- 把「倾向」删掉：「倾向表达」→「善于表达」
- 把「传统上」删掉：「传统上归在离散一类」→「主离散」
- 把置信度提示删掉
- 把「结构上」删掉：「结构上找不到对应位置」→「这事没着落」

这几种改动读起来都更顺，也都越了界。

## 用户问「准不准」

据实说：这是一套按出生时刻推演的传统模型，它给出的是一个结构，
不是对本人的鉴定，也不预告将会发生什么。每一条都可以展开看它是怎么算的 ——
看得到算法，才判断得了要不要当真。

不要说「信则有」，那是把判断推回给用户；也不要说「很准」。
